# <a id="3f2d65dd82be800b9c3ff7f9fbda8eb9" />Financial Analysis and Projection

<a id="3f2d65dd82be8051ad0ac4897f0aa0d0" />Our initial [Market Research ](/ubc-vancouver/administration/market-research-) confirms that there is a strong need for faster answers than culture-based testing can provide.  FAST was built to meet that need and help clinicians improve patient outcomes in a more sustainable way.  Our financial analysis shows how this clinical value translates into a viable business.

# <a id="3f2d65dd82be80169b31fee620b39814" />Marketing Strategy

<a id="3f2d65dd82be807d8b6be527ffbad070" />**Beachhead market:** As previously outlined  consists of hospital emergency departments, urgent care centers, and community clinics treating urinary tract infections (UTIs).

<a id="3f2d65dd82be80339780dcc772b8260e" />**Approach:**

- <a id="3f2d65dd82be80449c1feea924f76786" />Secure early intellectual property for the microfluidic chip and biosensor
- <a id="3f2d65dd82be80579fa3f574bb50aebc" />Engage Health Canada and biosafety authorities to confirm IVD regulatory pathways
- <a id="3f2d65dd82be80619e88c0476e68e893" />Build relationships with clinical early adopters
- <a id="3f2d65dd82be805ca17ef4bc5be73e42" />Validate platform feasibility through lab benchmarking studies and pilot trials showing significant reductions in diagnostic turnaround time and healthcare costs compared to traditional culture-based testing

<a id="3f2d65dd82be80169622cf8df17cf185" />

## <a id="3f2d65dd82be80ac8220d0bd562376f0" />First Product & Deliverables

<a id="3f2d65dd82be8069beefc48f8bec64cc" />**Launch timing:** Year 4+

<a id="3f2d65dd82be80c69625eec913f2bb46" />A point of care UTI diagnostics platform consisting of:

- <a id="3f2d65dd82be80a8af6ef7dd513a3826" />An affordable fluorescence reader
- <a id="3f2d65dd82be80b4a655c2acd34e436b" />Single-use microfluidic test cartridges

<a id="3f2d65dd82be8090a6b3f62c8f9c9127" />Validated through clinical sample trials, the kits let healthcare providers detect antibiotic resistance in under 24 hours.

<a id="3f2d65dd82be8047b5acf05fab0efcdf" />**Additional service:** Pilot testing for acute care facilities, demonstrating:

- <a id="3f2d65dd82be800eb85fffcbff2ea59f" />Real-world workflow integration
- <a id="3f2d65dd82be8062996ee0ab4801e16b" />Improved clinical outcomes
- <a id="3f2d65dd82be80bc9613e48f51d765cd" />Enhanced antimicrobial stewardship

## <a id="3f2d65dd82be80269d92df4d407a86b2" />Scaling & Commercialization Pathway

<a id="3f2d65dd82be80b8b077d752a86a9ed4" />Growth is tied directly to regulatory and operational milestones.

<a id="3f2d65dd82be803cb8cdc950190b2be6" />

| <a id="3f2d65dd82be80a8be4fce7f3998ce90" />Timeline  | Focus                                                                                                                                  |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="3f2d65dd82be80afac17e48f76909f19" />Years 1-2 | In-house research, patent filings, analytical validation, quality management system, Q-submission to Health Canada                     |
| <a id="3f2d65dd82be8014a65ac54853d28b9e" />Year 3    | Biocompatibility and technical safety testing, early human testing at partner sites under ethics approval, FDA submission              |
| <a id="3f2d65dd82be80688a2fe6b1d1c88e35" />Year 4    | Submit for Health Canada medical device license, run multi-site trials, complete the pharmacoeconomic review to support reimbursement  |
| <a id="3fcd65dd82be80cc96a6eb5b4ce4c906" />Year 5    | Commercial launch following licensing; scale to more clinics and hospitals, implement post-market surveillance, scale up manufacturing |
| <a id="3fcd65dd82be80179521f321208f38ea" />Year 6+   | Expand to international markets and adjacent applications (e.g., veterinary or agriculture) once domestic footprint is established     |

## <a id="3f2d65dd82be80818897f3066ab7d303" />Investor Engagement & Demonstration

<a id="3f2d65dd82be80009bd8ef680ee137f0" />We rely on clear data and live technical demonstrations to show investors what is possible:

- <a id="3f2d65dd82be80518339cfbf12b80b9d" />Showcase live point-of-care fluorescence readouts at scientific conferences
- <a id="3f2d65dd82be801ca0f6f9d9f0e8ffd8" />Present functional hardware prototypes
- <a id="3f2d65dd82be80acb9f7f0bc2ce7e5ac" />Provide validated metrics on cost savings, rapid turnaround times, and reduced empirical prescribing risks

<a id="3f2d65dd82be8098bc36f5f8c00ee018" />This transparent approach ensures early-stage capital directly drives key technical, regulatory, and commercial milestones.
