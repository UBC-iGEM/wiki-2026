# <a id="3f2d65dd82be800b9c3ff7f9fbda8eb9" />Financial Analysis and Projection

<a id="3f2d65dd82be8051ad0ac4897f0aa0d0" />Our initial [Market Research ](/ubc-vancouver/administration/market-research-) confirms that there is a strong need for faster answers than culture-based testing can provide.  FAST was built to meet that need and help clinicians improve patient outcomes in a more sustainable way.  Our financial analysis shows how this clinical value translates into a viable business.

# <a id="3f2d65dd82be80169b31fee620b39814" />Go-To-Market Strategy

<a id="3f2d65dd82be807d8b6be527ffbad070" />As previously outlined our beachhead market consists of family physician clinics and community pharmacies in British Columbia, where UTIs can be diagnosed and antibiotics are prescribed without timely susceptibility test results. Our approach will consist of three main points

- <a id="3f2d65dd82be80449c1feea924f76786" />Finding early adopters by working with antimicrobial stewardship programs, pharmacy associations and family practice associations to identify clinicians who want point-of-care susceptibility data.
- <a id="3f2d65dd82be80579fa3f574bb50aebc" />Run pilots directly with the payer (provincial health authority) via innovation programs, so the province is part of the process of generating evidence to eventually device on coverage
- <a id="3f2d65dd82be80619e88c0476e68e893" />Design experiments to target the evidence that stakeholder groups want

<a id="3fdd65dd82be805d8888ff65ffd1a5aa" />

| <a id="3fdd65dd82be80838fa8e65faa91458f" />Stakeholder Group                       | Wants                                                                                            |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| <a id="3fdd65dd82be806d832ac766b0432934" />Users (family physicians & pharmacists) | FAST can be conducted in a short window and tells them whether their chosen antibiotic will work |
| <a id="3fdd65dd82be8021ac7ad04e6edd128f" />Patients (beneficiaries)                | The right antibiotic is chosen the first time around, resulting in fewer return visits           |
| <a id="3fdd65dd82be8017b754f215e5590412" />Provincial Health Plan (payer)          | Lower total cost to the health care system from fewer failed treatments                          |

## <a id="3f2d65dd82be80ac8220d0bd562376f0" />First Product & Deliverables

<a id="3f2d65dd82be80c69625eec913f2bb46" />Our first product, which we anticipate to obtain by Year 4 would be a point of care UTI diagnostics platform consisting of:

- <a id="3f2d65dd82be80a8af6ef7dd513a3826" />An affordable fluorescence reader
- <a id="3f2d65dd82be80b4a655c2acd34e436b" />Single-use microfluidic test chips

<a id="3f2d65dd82be8090a6b3f62c8f9c9127" />From this product, we would host **p**ilot testing programmes for acute care facilities, demonstrating the ability for FAST to integrate with existing workflows, create improved clinical outcomes and enhance antimicrobial stewardship

## <a id="3f2d65dd82be80818897f3066ab7d303" />Investor Engagement & Demonstration

<a id="3f2d65dd82be80009bd8ef680ee137f0" />To maintain investor interest and attract additional funding, we would tie funding rounds on clear data and live technical demonstrations to show investors what is possible and our progress which may include:

- <a id="3f2d65dd82be80518339cfbf12b80b9d" />Showcase live point-of-care fluorescence readouts at scientific conferences
- <a id="3f2d65dd82be801ca0f6f9d9f0e8ffd8" />Present functional hardware prototypes
- <a id="3f2d65dd82be80acb9f7f0bc2ce7e5ac" />Provide validated metrics on cost savings, rapid turnaround times, and reduced empirical prescribing risks

<a id="3f2d65dd82be8098bc36f5f8c00ee018" />This transparent approach ensures early-stage capital directly drives key technical, regulatory, and commercial milestones.

<a id="3f2d65dd82be803cb8cdc950190b2be6" />

| <a id="3f2d65dd82be80a8be4fce7f3998ce90" />Timeline  | Focus                                                                                                                                  |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="3f2d65dd82be80afac17e48f76909f19" />Years 1-2 | In-house research, patent filings, analytical validation, quality management system, Q-submission to Health Canada                     |
| <a id="3f2d65dd82be8014a65ac54853d28b9e" />Year 3    | Biocompatibility and technical safety testing, early human testing at partner sites under ethics approval, FDA submission              |
| <a id="3f2d65dd82be80688a2fe6b1d1c88e35" />Year 4    | Submit for Health Canada medical device license, run multi-site trials, complete the pharmacoeconomic review to support reimbursement  |
| <a id="3fcd65dd82be80cc96a6eb5b4ce4c906" />Year 5    | Commercial launch following licensing; scale to more clinics and hospitals, implement post-market surveillance, scale up manufacturing |
| <a id="3fcd65dd82be80179521f321208f38ea" />Year 6+   | Expand to international markets and adjacent applications (e.g., veterinary or agriculture) once domestic footprint is established     |
