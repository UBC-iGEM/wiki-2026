# <a id="3ffd65dd82be80388cc2c9ada9781ae0" />Objective

<a id="3ffd65dd82be8024935dffdcde475b6f" />Test mixing and behaviour of fluids in microfluidic chip prototypes.

<br id="3ffd65dd82be80debc54d3744d6b8916" />

# <a id="3ffd65dd82be809fb581d2167760e844" />Materials

<a id="3ffd65dd82be808abb3ed3cce3c2d371" />2x 1 mL syringe

<a id="3ffd65dd82be800a9fa6db217cad1f56" />2x Colourful liquid (1 mL per test run)

<a id="3ffd65dd82be801d91d8f138a1a5cb2c" />1x Microfluidic chip

<a id="3ffd65dd82be80f8b47bfba869f613ce" />2x pipette tips

<a id="3ffd65dd82be80bc9e8cd1473aa74d82" />1x scotch tape

<br id="3ffd65dd82be809da2a3c566604b1fbf" />

# <a id="3ffd65dd82be80eba30acc2eb8289ec6" />Method

1. <a id="3ffd65dd82be807090b3f0b3e2d92c01" />Cut the ends off of the pipette tips and place them so they’re standing in the inlet wells of the microfluidic chip.
2. <a id="3ffd65dd82be8003956decf4804a1370" />Load each syringe with a different colourful liquid.
3. <a id="3ffd65dd82be803e91b1f06ead27a768" />Tape over one of the outlet wells.
4. <a id="3ffd65dd82be80668ab6cd0667b6653d" />Drip liquid from the syringes into the inlet wells. Videotape and observe.
