1. <a id="3ffd65dd82be80448aefc0d1b57dfe8d" />Make sure everything’s sterile
2. <a id="3ffd65dd82be80d6b263c9b89c0598f9" />Drop in the magnetic stirrer
3. <a id="3ffd65dd82be8075b7d3e304ed824514" />Screw the lid onto the 1L mason jar
4. <a id="3ffd65dd82be8023acc3dd3375fe7fd4" />Feed two tubings through the small holes on the lid
5. <a id="3ffd65dd82be8032ab02ca0b05e85f43" />Parafilm
6. <a id="3ffd65dd82be805386d5ef08313a5b5c" />Unscrew then Insert pH sensor into the largest hole.
7. <a id="3ffd65dd82be808a9949c0f9510ca2e7" />Parafilm
8. <a id="3ffd65dd82be80409ed4f80cf613e71e" />Insert temperature sensor
9. <a id="3ffd65dd82be8015ad8edc126634b6b0" />Adjust the temperature sensor to an appropriate position before parafilming
10. <a id="3ffd65dd82be80afb7b1f4f05114922b" />Screw on the electronic housing, the window should be facing the person assembling
11. <a id="3ffd65dd82be80abb258f504a07ccd5e" />Pull the wire of both sensors through the window from the bottom opening
12. <a id="3ffd65dd82be806b8728db6e3b84819d" />Secure the temp sensor onto the housing wall
13. <a id="3ffd65dd82be80689738de9db5dd601b" />Put in breadboard and Arduino. Secure using 3D printed screw
14. <a id="3ffd65dd82be8061b65bf546af3d9d48" />Feed the pH sensor wire back in and lock its end onto the pH meter board
15. <a id="3ffd65dd82be80d3b11ed630243cca14" />Secure the pH meter board
16. <a id="3ffd65dd82be80889fb4d91d6d6a5e8a" />Plug Arduino into computer
17. <a id="3ffd65dd82be80848dc5d5bb448c971a" />Insert peristaltic pump
18. <a id="3ffd65dd82be806a9f2cc11e06431ef3" />Connect one tubing to the pump and parafilm. Make sure it is connect to the side that outputs air
19. <a id="3ffd65dd82be80f89be7c6268b1d50e7" />Connect the other side of the pump to a sterile air filter and parafilm
20. <a id="3ffd65dd82be80799142c5d8b463071d" />Feed the other tubing out of the window. Attach a syringe to it for sampling
21. <a id="3ffd65dd82be80a88a91d67d5213cf22" />Wire the pump to power
22. <a id="3ffd65dd82be807298aaee2b791eb7e8" />Place the assembled bioreactor onto a magnetic stirring plate
