# <a id="3c1d65dd82be80eeba0dc9f114de2792" />OBJECTIVE

> <a id="3c1d65dd82be800eb057c215bc782623" />Ensure that pH readings during experimentation will be fully accurate and reflect the true pH value of the probe tip environment.

## <a id="3c1d65dd82be80dba49cde4ded35adb0" />**PRODUCT:**

<a id="3fdd65dd82be80a0910ed0a8a3fea33e" />DFRobot SEN0169 Gravity: Analog pH Sensor (PRO)

## <a id="3c1d65dd82be804dbce8eaee0bb15e35" />**DOCUMENTATION:**

- <a id="3c1d65dd82be807d9cdaf874604ec344" />Official DFRobot product page: [https://wiki.dfrobot.com/sen0169/](https://wiki.dfrobot.com/sen0169/)

# <a id="3c1d65dd82be80a8b434d5761240c664" />OVERVIEW

<a id="3c1d65dd82be80e6b6ffe58df305125e" />Calibration is done by adjusting **BOTH** the software code on arduino IDE, as well as manually adjusting the potentiometer on the pH meter board.

- <a id="3c1d65dd82be80768898eb6180f7beb0" />The potentiometer is the blue block close to the BNC connector (probe attachment). Note that there is a small screw at the top that must be adjusted with a flathead screwdriver

# <a id="3c1d65dd82be8077b932ff695102f085" />PROCEDURE

## <a id="3c1d65dd82be80a1b98de9de9714ab96" />MATERIAL PREP

- <a id="3c1d65dd82be80fdb082faba32c1f326" />pH 7.0 solution
- <a id="3c1d65dd82be80f2baa3e043cb7bee8d" />pH 4.0 solution

- <a id="3c1d65dd82be804d90e9dfd5dc7a3789" />***Do not wipe or rub the tip of the probe harshly***
- <a id="3c1d65dd82be80a7b4a1fa9b5b951dc3" />***Always rinse probe with distilled water when moving between solutions***

## <a id="3c1d65dd82be80ef865de6e8e40f44b2" />HARDWARE SETUP

1. <a id="3c1d65dd82be806f940cd1a7ec52ac1e" />pH probe ↔ pH meter board via BNC connector
2. <a id="3c1d65dd82be8064877cfdb06cf8596e" />pH meter board ↔ arduino via 3-pin connector
   1. <a id="3c1d65dd82be80e08bd3e8be23c435d8" />blue: signal out to any analog pin
      1. <a id="3c1d65dd82be808c9aeee7fde3680a62" />should keep in mind which pin is being used, as this will reflect in the code
   2. <a id="3c1d65dd82be801992c7ff931908048e" />red: power to 5V
   3. <a id="3c1d65dd82be80169048f18ac3699d41" />black: gnd to gnd
3. <a id="3c1d65dd82be80c19913dcdadb40cadd" />arduino ↔ connect to laptop for power
4. <a id="3c1d65dd82be809f853dd7c79c44dd79" />flash code onto arduino:
   <a id="3fdd65dd82be805c98ffedb01441a74a" />
   ```c
   /*
    # This sample code is used to test the pH meter Pro V1.0.
    # Editor : YouYou
    # Ver    : 1.0
    # Product: analog pH meter Pro
    # SKU    : SEN0169
   */

   #define SensorPin A0  //pH meter Analog output to Arduino Analog Input 0
   #define Offset 0.00  //deviation compensate
   #define LED 13
   #define samplingInterval 20
   #define printInterval 800
   #define ArrayLength  40  //times of collection

   int pHArray[ArrayLength]; //Store the average value of the sensor feedback
   int pHArrayIndex=0;

   void setup(void)
   {
     pinMode(LED,OUTPUT);
     Serial.begin(9600);
     Serial.println("pH meter experiment!"); //Test the serial monitor
   }

   void loop(void)
   {
     static unsigned long samplingTime = millis();
     static unsigned long printTime = millis();
     static float pHValue,voltage;
     
     if(millis()-samplingTime > samplingInterval)
     {
         pHArray[pHArrayIndex++]=analogRead(SensorPin);
         if(pHArrayIndex==ArrayLength)pHArrayIndex=0;
         voltage = avergearray(pHArray, ArrayLength)*5.0/1024;
         pHValue = 3.5*voltage+Offset;
         samplingTime=millis();
     }
     //Every 800 milliseconds, print the state of the LED indicator
     if(millis() - printTime > printInterval) 
     {
       Serial.print("Voltage:");
           Serial.print(voltage,2);
           Serial.print("    pH value: ");
       Serial.println(pHValue,2);
           digitalWrite(LED,digitalRead(LED)^1);
           printTime=millis();
     }
   }

   double avergearray(int* arr, int number){
     int i;
     int max,min;
     double avg;
     long amount=0;
     if(number<=0){
       Serial.println("Error number for the array to avraging!/n");
       return 0;
     }
     // less than 5, calculated directly statistics
     if(number<5){   
       for(i=0;i<number;i++){
         amount+=arr[i];
       }
       avg = amount/number;
       return avg;
     }
     else{
       if(arr[0]<arr[1]){
         min = arr[0];max=arr[1];
       }
       else{
         min=arr[1];max=arr[0];
       }
       for(i=2;i<number;i++){
         if(arr[i]<min){
           amount+=min;        //arr<min
           min=arr[i];
         }else {
           if(arr[i]>max){
             amount+=max;    //arr>max
             max=arr[i];
           }else{
             amount+=arr[i]; //min<=arr<=max
           }
         }//if
       }//for
       avg = (double)amount/(number-2);
     }//if
     return avg;
   }
   ```
   1. <a id="3fdd65dd82be80849276eda87af15213" />letting the probe run while looking at the terminal on the Arduino IDE interface should read continuous values of voltage AND pH

## <a id="3c1d65dd82be804e8431c847bd0afea0" />CALIBRATION SOFTWARE

1. <a id="3c1d65dd82be805ba487c3cf65a30950" />Rinse probe tip with distilled water and gently dry
2. <a id="3c1d65dd82be801dbcc8f9c972a92f35" />Submerge tip into pH 7 solution
3. <a id="3c1d65dd82be80ee95eff22e3bbcf5e1" />Watch the terminal until a steady pH value is read
4. <a id="3c1d65dd82be80c99e21da751ca597ec" />Record steady pH value
5. <a id="3c1d65dd82be808cb417ffcccbd5f8f7" />Determine offset
   > <a id="3c1d65dd82be80db812acad15d7d7065" />Offset = 7.00 - steady pH value
6. <a id="3c1d65dd82be80f483f8e473b0cf6659" />Implement offset into .ino code
   <a id="3c1d65dd82be80ebb0a8de0380ea9cfa" />
   ```javascript
   #define Offset 0.00   // change this value!
   ```
7. <a id="3c1d65dd82be803f85c1ea7a40d74798" />Save file and reflash the code onto the arduino
8. <a id="3c1d65dd82be8048971ede6fb64c926b" />Check that pH readings are within range of pH 7

<Callout icon="🥼">
  <a id="3cfd65dd82be80df9533ebda01516fa1" />Operator notes: Offset is set to 0.35
</Callout>

## <a id="3c1d65dd82be808faeb3de25a4ef9a8e" />CALIBRATION HARDWARE

1. <a id="3c1d65dd82be800baccfe922c79e57b3" />Rinse probe tip with distilled water and gently dry
2. <a id="3c1d65dd82be8068bbffcb059cc72e5d" />Submerge tip into pH 4 solution
3. <a id="3c1d65dd82be8067b88ade7dd2369dce" />Watch the terminal until a steady pH value is read
4. <a id="3c1d65dd82be80bf9ac8d56e6b525676" />Adjust the potentiometer until a pH value of 4 is read
   1. <a id="3c1d65dd82be8034b4a1e69a06744d2d" />2 way knob: one way is increasing pH, other way is decreasing pH
5. <a id="3c1d65dd82be80d79effefa207b9c1da" />DONE WITH POTENTIOMETER! DO NOT ADJUST ANYMORE!
6. <a id="3fdd65dd82be809e8f21e006c7697da9" />Once both sets of calibration have been completed, check back that the probe is correctly reading pH 7.0 in pH 7.0 solution and pH 4.0 in pH 4.0 solution
