## <a id="3c1d65dd82be8065a97ccc8b792ed066" />Procedure

### <a id="3c1d65dd82be80f0bb26db903acfd73a" />Day 1  - Prep Cultures + AB stocks + Media & Water

<a id="3c1d65dd82be80dd8e7ecff57e3f0563" />**<u>WT & Cephalexin Culture Prep</u>**

1. <a id="3c1d65dd82be80d38596cb487fb7555d" />Add \~7mL LB media to two culture tubes, recap
2. <a id="3c1d65dd82be808da124ef625d9b9a73" />Into one culture tube add Cephalexin to around \~10mg/mL
3. <a id="3c1d65dd82be800eab92df6f45463ce7" />Prepare an inoculation loop
4. <a id="3c1d65dd82be80bd938afc5457273d3c" />Obtain glycerol stocks from -80C (where?)
5. <a id="3c1d65dd82be8055877ac4a42d427780" />Sterilize inoculation loop, when cooled, scrap top of glycerol stock with inoculation loop, place in culture tube and stir. Recap loosely
6. <a id="3c1d65dd82be8047a304c259f98c67c8" />Place glycerol tube back into -80C (where?)
7. <a id="3c1d65dd82be80208548d9142033487e" />Place culture tube in 37C room, 200-250rpm, over night

<Callout icon="🥼">
  <a id="3c1d65dd82be804dbd30dbcc33760a30" />Tubes prepped and place on upper shaker on 37C room
</Callout>

### <a id="3c1d65dd82be80dc90a5d27fc8ebebee" />Day 2 - Plate Preparation

<Callout icon="🥼">
  <a id="3c1d65dd82be8030a6dfcfe42729508d" />Cephalexin tube was clear while no antibiotic tube was cloudy.
</Callout>

<a id="3c2d65dd82be80139342f63d675aa07e" />**<u>Prepare Tobramycin Stock</u>**

1. <a id="3c2d65dd82be8005aa87eb84ecab4f3d" />Read potency on antibiotics. Calculate amount needed to create a 1 mg/mL master stock of 10 mL
2. <a id="3c2d65dd82be80de8174c6fd11ab0d5a" />Dissolve in water, vortex, and filter

<Callout icon="🥼">
  <a id="3c2d65dd82be80468a32d5fe215011db" />For tobramycin, the target weight for 1mg/mL in 15mL is:

  <a id="3c2d65dd82be807983e7f68a1c212303" />$10 mL \cdot \frac{1mg}{1mL} \cdot \frac{1mg}{0.972mg} = 10.29mg$

  <a id="3c2d65dd82be80b08cabf448d375640a" />Actual: 10.2 - 0.0 mg = 10.2mg→ 9.91mg active, 9.91mL

  <a id="3c2d65dd82be802aa30bc269235397df" />MilliQ H2O added
</Callout>

<a id="3c1d65dd82be804aaaefd018fb6314ba" />**<u>Prepare Cephalexin Stock</u>**

1. <a id="3c1d65dd82be80e9856cf153c9ebe4af" />Read potency on antibiotic. Calculate amount needed to create a 1 mg/mL master stock of 10 mL
2. <a id="3c1d65dd82be8044ac18dea48fb2e072" />Dissolve in water, vortex, and filter
3. <a id="3c1d65dd82be80c1b040efb691604603" />Aliquot 3mL into 5mL tubes, label with date and identity
4. <a id="3c1d65dd82be8041b2aecfdf776c787f" />Store in -20C

<Callout icon="🥼">
  <a id="3c1d65dd82be80cab4fedf92c4c0bf14" />For cephalexin, the target weight for 1mg/mL in 15mL is:

  <a id="3c1d65dd82be8048a766fb9646e4e26b" />$10 mL \cdot \frac{1mg}{1mL} \cdot \frac{1mg}{0.999mg} = 10.01mg$

  <a id="3c1d65dd82be80b5b4b7f3778a88bc1b" />Actual weight was 13.7-2.2 = 11.5→ 11.5mg active , 11.5 MilliQ H2O added
</Callout>

   1. <a id="3c1d65dd82be80b280a5c0d2d33e94c7" />These are 2x concentrations

| ----------------------------------------------------- | -------------- | --------------- | ----------- |
| <a id="3c1d65dd82be80eb8674e6297e5e636d" />Tobramycin | 32             | 32              | 968         |
| <a id="3c1d65dd82be804291a0ef7d9fe8f0ba" />Cephalexin | 512            | 512             | 488         |

1. <a id="3c1d65dd82be80078343fba72de85c1d" />Vortex each tube

- <a id="3c1d65dd82be805ea923d2989d6e6001" />The water moat is to create an evaporation buffer
- <a id="3c1d65dd82be802ea847fb174185dd41" />Growth control is no antibiotic to compare against
- <a id="3c1d65dd82be80dd94f0fcb86fd8159a" />Sterility control is the media blank

<br id="3c1d65dd82be803394efe30354cb7a8b" />

1. <a id="3c1d65dd82be805ea093ed0ee87edcce" />For each moat well, dispense 200uL sterile water
2. <a id="3c1d65dd82be806ea108c8db5dd9298b" />Dispense 100uL LB into all interior wells except column 2 (cols 3-11, rows B-G)
3. <a id="3c1d65dd82be80a59a69cf834bcce700" />Dispense an additional 100uL LB to the sterility well (G11)
4. <a id="3c1d65dd82be80118eb2dcf413afbf29" />Dispense 200uL of the working stock into column 2
5. <a id="3c1d65dd82be8066b761e300a1ab4cdd" />Mix throughly (4-5 up-downs), then pipette 100uL into the next column to the right
6. <a id="3c1d65dd82be802d8956d49b79b541f7" />Repeat step 4 until you reach column 10, discard 100uL from column 10
   1. <a id="3c1d65dd82be8052834ad3ba3ecdd443" />You should have 100uL in each well, with 2x the concentration of anbiotic
7. <a id="3c1d65dd82be80539067ca0d10567d1b" />Repeat steps 4-6 for all rows
8. <a id="3c1d65dd82be8001be80fe9de1e1fe23" />When you are done with a plate, remember to place the lid back on

<a id="3c1d65dd82be80b6a08fe8104d71476f" />**<u>Inoculum Preparation</u>**

1. <a id="3c1d65dd82be80539f6fe5a971873dcc" />Obtain the overnight culture and mix throughly
2. <a id="3c1d65dd82be80ba89c2c94cca457e81" />In a 1cm cuvette, add 100uL of the culture and 1900 uL of LB and read OD 600
   1. <a id="3c1d65dd82be800e9149fd7f494edbde" />Use plain LB media as a blank
3. <a id="3c1d65dd82be80178c35fa3490d37143" />Adjust the suspension with LB to a target OD600 of 0.1
4. <a id="3c1d65dd82be804daa1de3ce0494b3c9" />Invert the tube to mix

<a id="3c1d65dd82be8029b4bad3874d42e31f" />**<u>Plate Addition</u>**

1. <a id="3c1d65dd82be80ac86f2d50230c2c98e" />Except for the sterility control well, add 100uL of the prepared inoculum to all interior (non-moat) wells
