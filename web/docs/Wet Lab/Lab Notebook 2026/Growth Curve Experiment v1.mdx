# <a id="3c4d65dd82be80baaa73f9d9aa87e109" />Background

## <a id="3c4d65dd82be803ebf96d83e1cef996c" />Objective

<a id="3c4d65dd82be80218dc0d3871ac7c267" />To measure the baseline growth kinetics of each strain and determine burden of the backbone w/wo promotor+sfGFP.

<Callout icon="🗣">
  <a id="3c4d65dd82be8023a0ddfcb7c161ffc7" />**How do our biosensors grow compared to normal EPI300, and EPI300+CmR, at both 37C and RT (22C)?**
</Callout>

<a id="3c4d65dd82be80d4bfded827912f445d" />Another piece of information we obtain is the level of basal expression of GFP at RT and 37C.

# <a id="3c4d65dd82be80cf8ca6d2ea564cee16" />Experiment

## <a id="3c4d65dd82be80ff909fd41b1db3087a" />Procedure

### <a id="3c4d65dd82be80f2bd09dd39622f180f" />Day 1+2 - Streak and Starter

1. <a id="3c4d65dd82be80758711efabf677680b" />Streak each strain and grow overnight at 37ºC
   1. <a id="3c4d65dd82be8097b066fb52ccd6d6d3" />Use LB agar plates for strain 1, LB-Cm plates for strains 2-4
2. <a id="3c4d65dd82be809193b5f15c77e07355" />Pick 3 colonies per strain, inoculate into separate tubes w/ 3mL of media each and grow overnight at 37C , 200rpm
   1. <a id="3c4d65dd82be8045a713dba874f4770a" />Use LB for strain 1, LB-Cm for strains 2-4

<a id="3c4d65dd82be80219d18c67bb9492de8" />

| <a id="3c4d65dd82be805fbe6dc6ff4514189e" />Backbone-only (Strain 2) | BB1, BB2, BB3 |
| <a id="3c4d65dd82be80c9aae5cca00f2cf998" />RecA (Strain 3)          | RC1, RC2, RC3 |
| <a id="3c4d65dd82be806cb11ff9ff8aeab784" />CpxP (Strain 4)          | CX1, CX2, CX3 |

### <a id="3c4d65dd82be804ea633c96f14e618d9" />Day 3 - Plating + Experiment

1. <a id="3c4d65dd82be80f0aacde9f3526a1c45" />Measure OD600 of each tube, diluting into linear range if needed
2. <a id="3c4d65dd82be80c0981bcd61a3f5bf43" />For cells cultured in LB-Cm, pellet \~1mL, discard supernatant and resuspend in LB media, LB-Cm for those with plasmids.
3. <a id="3c4d65dd82be80209e3cd6b6a697e404" />Dilute all cultures to 0.02 OD600 in LB media
4. <a id="3c4d65dd82be80028b6bd3d8d7a44bd9" />Dispense 200uL per well using layout below. Create a total of 2 plates
