# Background

## Objective

Repeat of [Growth Curve Experiment v1](/wet-lab/lab-notebook-2026/growth-curve-experiment-v1) due to equipment error and media contamination

# Experiment

## Materials and Equipment

- LB Broth
- LB-Cm Broth (17mg/ml)
- 96-well flat bottom, clear plate + lid
- DI water
- Culture tubes

## Procedure

### Day 1 - Streaking

1. Streak each strain and grow overnight at 37ºC
   1. Use LB agar plates for strain 1, LB-Cm plates for strains 2-4
2. Additionally, streak media from bottles on LB agar plates to check for sterility

### Day 2 - Starter Cultures

1. Pick 3 colonies per strain, inoculate into separate tubes w/ 3mL of media each and grow overnight at 37C , 200rpm
   1. Use LB for strain 1, LB-Cm for strains 2-4

| Condition                | Tube IDs      | Media |
| ------------------------ | ------------- | ----- |
| Wild Type (Strain 1)     | WT1, WT2, WT3 | LB    |
| Backbone-only (Strain 2) | BB1, BB2, BB3 | LB-CM |
| RecA (Strain 3)          | RC1, RC2, RC3 | LB-CM |
| CpxP (Strain 4)          | CX1, CX2, CX3 | LB-CM |

### Day 3 - Plating + Experiment

1. Measure OD600 of each tube, diluting into linear range if needed
2. Dilute all cultures to **0.02** OD600 in LB media
3. Dispense 200uL per plate using layout below. Create a total of 2 plates
