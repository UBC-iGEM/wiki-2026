# <a id="36dd65dd82be807f9ef2e0f79aecb4ac" />Purpose

<a id="36dd65dd82be807795ddfa08a5de8412" />The purpose of this experiment is to clone the plasmid CpxP and transform the plasmid into DH5a *E. coli!*

# <a id="36dd65dd82be806da277c6a956ef33f7" />Materials & Methods

<a id="36dd65dd82be805ca951eb2e406f9842" />

|                                                               |                         |                                 |
| ------------------------------------------------------------- | ----------------------- | ------------------------------- |
| <a id="36dd65dd82be80b4ad00c7544314ddda" />**DNA Components** | **Restriction Enzymes** | **Cloning Reagents/Kits**       |
| <a id="36dd65dd82be80adaa5ce79d35b95806" />pSB1C3             | PstI                    | 2x HiFi DNA Assembly Master Mix |
| <a id="36dd65dd82be80219935decbc07014f5" />CpxP gBlock        | EcoRI                   | Miniprep Kit                    |
| <a id="36dd65dd82be80eb8d29cf7350af4ff5" />                   |                         | DNA gel Extraction              |

<a id="36dd65dd82be80b8bc48c8c0defb4287" />**Step 1: Linearizing Plasmid Backbone**

1. <a id="36dd65dd82be80239571e3c77b64159b" />Pick bacteria from the glycerol stock and culture in 5 mL of Chloramphenicol LB media overnight while shaking
2. <a id="36dd65dd82be80f3a2a0d554bc39f600" />Extract plasmid via Miniprep kit and measure DNA concentration via Nanodrop
3. <a id="36dd65dd82be803d803ce25c0685a633" />Linearize the plasmid and remove the RFP gene using restriction enzymes PstI and EcoRI.
   1. <a id="36dd65dd82be80c48edafbaead690781" />Follow the reagent mixture below for linearization:

<a id="36dd65dd82be803c9bc2d05405c0c2e3" />**Table 1. Reagent mix and amount**

<a id="36dd65dd82be80409e5ed4131ea34eff" />

|                                                                               |            |
| ----------------------------------------------------------------------------- | ---------- |
| <a id="36dd65dd82be802287cdf2cac74d0cf3" />**Plasmid Linearization Reagents** | **Amount** |
| <a id="36dd65dd82be807ab161c7b48d0d71af" />Plasmid                            | 1 ug       |
| <a id="36dd65dd82be80c999f2d0b0156ba07f" />10x rCutSmart™ Buffer              | 4 uL       |
| <a id="36dd65dd82be804bb6e5cc979f8de7ba" />PstI restriction enzyme            | 0.8 uL     |
| <a id="36dd65dd82be80e98374d41870ee43cf" />EcoRI restriction enzyme           | 0.8 uL     |
| <a id="36dd65dd82be806c84c5ce0f919a74f5" />ddH2O                              | to 40 uL   |
| <a id="36dd65dd82be802592eac1c449d56ab1" />**Total Volume**                   | **40 uL**  |

<a id="36dd65dd82be80158a60cf036ef6422c" />Note: Add the reagents in this order: ddH20, plasmid, 10x rCutSmart buffer, restriction enzymes

1. <a id="36dd65dd82be80669835d9df803a037b" />Incubate the mixture at 37C for \~ 1 hr
2. <a id="36dd65dd82be806da847fcc3ab936dd5" />Run gel electrophoresis on the incubated mixture
   1. <a id="36dd65dd82be803eb935ffe09869a500" />Gel Preparation
      1. <a id="36dd65dd82be80d7bac9c9cf3869bad4" />500 ug Agarose + 50 mL 1x TAE buffer → 1 min Microwave
      2. <a id="36dd65dd82be80dcaf33ee2b8a56278d" />Add 10 uL Ethidium Bromide/Syber Safe into the heated mixture → swirl
      3. <a id="36dd65dd82be80fd8e49c7a49955a6c7" />Pour into gel casting tray + insert comb (remove all bubbles)
      4. <a id="36dd65dd82be808fa157df1ced533afb" />Let gel sit for 30 min to solidify
   2. <a id="36dd65dd82be80e8b287fc6916a802e4" />Dilute 6x loading dye to 1x by adding to incubated mixture
      1. <a id="36dd65dd82be80e79e3eeff70c9382a6" />For 40 uL volume, add 8 uL of 6X gel loading dye (scale appropriately)
   3. <a id="36dd65dd82be80d39096fe542f783747" />Run gel electrophoresis w/ following parameters: 130 V, 400 A, 30 minutes
      1. <a id="36dd65dd82be8035b828c2ba71bb40ea" />You should see 2 bands → linearized plasmid + cut-out fragment
3. <a id="36dd65dd82be80108ddad9b8098a4283" />Extract linearized plasmid via DNA gel extraction kit and Nandrop!
   1. <a id="36dd65dd82be8009a4c2fdb8dc3841fb" />Only cut out the linearized plasmid precisely (identify using DNA ladder)

<a id="36dd65dd82be80e7bf2ee147a2bee507" />**Step 2: Insert gBlock into Linearized Plasmid via HIFI Assembly**

1. <a id="36dd65dd82be8081b85df69abcbd2041" />Insert gBlock via HIFI Assembly following protocol below:
   1. <a id="36dd65dd82be802db993d09d43655315" />Prepare reaction mixture with the following reagents:

<a id="36dd65dd82be808d8edae79194ef4639" />**Table 2. Reagent Mix and amount**

<a id="36dd65dd82be80639880cdfb2a268902" />

|                                                                                |            |
| ------------------------------------------------------------------------------ | ---------- |
| <a id="36dd65dd82be80d48d53e9b141a93104" />**HIFI Assembly Reaction Reagents** | **Amount** |
| <a id="36dd65dd82be8015a9eada963cec551f" />DNA backbone                        | 0.6 uL     |
| <a id="36dd65dd82be80a58b7cf40d6dd9c3fd" />gBlock                              | 0.3 uL     |
| <a id="36dd65dd82be8027a1c5fe1cfdfdae20" />HiFi DNA Assembly Master Mix        | 2 uL       |
| <a id="36dd65dd82be806e85b0f79d55693b3b" />ddH2O                               | 1.1 uL     |
| <a id="36dd65dd82be80b8a080f783c7b3a3f4" />**Total Volume**                    | **4 uL**   |

<a id="36dd65dd82be803aa3b8dbbbce68ef25" />Note: DNA calculation done using: [https://nebiocalculator.neb.com/#!/dsdnaamt](https://nebiocalculator.neb.com/#!/dsdnaamt)

1. <a id="36dd65dd82be80ea9aa8f7a583509ba9" />Incubate the HIFI assembly mixture at 50℃ for 15 min via Thermocycler

<a id="36dd65dd82be801598a5d1b24c921b3b" />**Step 3: Bacterial Transformation**

1. <a id="36dd65dd82be8061977cc1bdf2f20c38" />Add 5 uL cloned plasmid and 45 uL *high efficiency competent DH5a E. coli* in a 1:10 volume ratio.
2. <a id="36dd65dd82be807d941fd59f4e6126e4" />Incubate the mixture on ice for 30 min
3. <a id="36dd65dd82be801e8556de7cf6d1a6e6" />Heat shock the bacterial mixture at 42C for 30 seconds via waterbath or heatblock
4. <a id="36dd65dd82be80849ef2ddcf9ec18acd" />Incubate the mixture on ice for 5 min
5. <a id="36dd65dd82be80a68026cff8bc13bf05" />Add 100 uL of SOC media + incubate the mixture at 37C for 1 hour

<a id="36dd65dd82be8041b3c9ff4267d32b0c" />**Step 4: Plating bacteria**

1. <a id="36dd65dd82be8026b248d08f34534806" />Spin down and plate 50 uL of transformed bacteria on a chloramphenicol plate
2. <a id="36dd65dd82be80e1bdcdc1ab9342a450" />Incubate the plate overnight at 37C
