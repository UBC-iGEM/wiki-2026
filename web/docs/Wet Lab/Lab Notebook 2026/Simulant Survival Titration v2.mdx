# <a id="3d6d65dd82be805e8789fd45fac097b2" />Background

<Callout icon="🗣">

</Callout>

<a id="3d6d65dd82be80ab9b11dc1c1a9564f1" />We will repeat the experiment performed in [Simulant Survival Titration v1](/ubc-vancouver/wet-lab/lab-notebook-2026/simulant-survival-titration-v1)  in order to determine the antibiotic MIC range for cephalexin, amoxicillin, and kanamycin.

## <a id="3d6d65dd82be8073962cde4de4cc6a66" />Variables

- <a id="3d6d65dd82be80b4b0dad915cd40a649" />Independent: antibiotic concentration

- <a id="3d6d65dd82be80d99e43d1fbc448ceaa" />Objective: To find the optimal antibiotic concentration for each strain that maximises the number of colonies on the agar plate to use for future validations

# <a id="3d6d65dd82be8036b7dfec94ade11b14" />Experiment:

## <a id="3d6d65dd82be80688c39c87dec1fca8d" />Materials:

## <a id="3d6d65dd82be80d0a39af893d360f88a" />Procedure:

## <a id="3d6d65dd82be80c4b50bdb57b42d68d7" />Day 1 - Preparation of Inoculum & antibiotics

1. <a id="3d6d65dd82be8069bf6fc24b7bef6bb2" />Using glycerol stocks of each strain, inoculate 50 mL of the LB-Cm broth.
2. <a id="3d6d65dd82be80db8296fb778fdb1da5" />Grow each strain to mid-log phase (standardize OD600, e.g., 0.4–0.6) overnight at 37 ºC
   1. <a id="3d6d65dd82be8029b29ee3531d88172e" />LB-Gm = Gm resistant strain in LB-Cm
   2. <a id="3d6d65dd82be804a96f8e18f815903d9" />LB-Kn = Kan resistant strain in LB-Cm
   3. <a id="3d6d65dd82be808ca3bfdb04c3c741ad" />LB-Amox = beta lactam resistant strain in LB-Cm
   4. <a id="3d6d65dd82be80b39fdefcdd7ae44344" />LB-Cephalexin = beta lactam resistant strain in LB-Cm
3. <a id="3d6d65dd82be80f08874cddc39caba96" />**Prep of antibiotic stock**: Dissolve antibiotic in broth at 2× the highest concentration to be tested. Check concentration range on literature MIC values for your strain, spanning at least several dilutions below and above that value.

## <a id="3d6d65dd82be80bf81cff6096c3903e0" />Day 2

1. <a id="3d6d65dd82be806a8e91cc7afcc0efb1" />**Measuring OD600 of starting culture:** Use a spectrophotometer or plate reader to measure the OD600 of the culture. If OD600 is above 0.1, dilute with fresh broth. If it's between 0.09–0.1, proceed. If below 0.09, incubate 15–30 more minutes and re-check.
2. <a id="3d6d65dd82be803d859cfe8d60e351e9" />**Wash cultures**: To wash out the Cm from the LB-Cm cultures, centrifuge each strain at 4000 rpm for 10 mins. Resuspended each pellet in LB to maintain an OD of 0.1.
3. <a id="3d7d65dd82be8097b322c2248148822a" />**Make the diluted antibiotic media**: Create a total of 10ml by diluting antibiotics in Cm-free LB.
   1. <a id="3d7d65dd82be8080a197deaffcab088e" />Cephalexin
   2. <a id="3d7d65dd82be8036898bdddeb60f9692" />Amoxicilin
   3. <a id="3d7d65dd82be80459e5dd55437b131a7" />Gentamicin
   4. <a id="3d7d65dd82be8029b23ecab70f57c678" />Kanamycin
4. <a id="3d6d65dd82be808f9efef6d111bace3b" />**Steps 4-6 will be performed using a multichannel pipette, in triplicate**. Using the layout below, add 200 µL of LB broth to column 1. Add 100 µL of LB broth to columns 3-12, leaving column 2 empty.

1. <a id="3d6d65dd82be80399852d361c8b7f50f" />**Perform the serial dilution :** Add 200 µL from 2× antibiotic stock to column 2. Using a multichannel pipette, mix and transfer 100 µL from column 2 into column 3, mix, then transfer 100 µL from column 3 into column 4, and continue this pattern down to column 11. After mixing column 11, remove 100 µL and discard into waste so that all wells end at equal volume. Do not add any antibioitc media to column 12 (unstimulated control)
2. <a id="3d6d65dd82be806b932dd1ae1cabf382" />**Inoculating the plate**: Using a multichannel pipette, add 100 µL of the diluted standardized inoculum to every well in columns 2–12. Do not add inoculum to column 1 (blank control).
3. <a id="3d6d65dd82be8021ba29e767b0e6de79" />Seal and incubate: cover the plate with a sealing film, then a lid. Incubate at 37°C overnight.

## <a id="3d6d65dd82be80d28bbce1379f665871" />Day 3: Read the Plate and Determine MIC

1. <a id="3d6d65dd82be80ee91dcf393623b4034" />Remove the plate from the incubator, take off the lid and sealing film, and let it sit at room temperature for 15 minutes before reading.
2. <a id="3d6d65dd82be80b78b97eaf17a9d8424" />**Read OD**: Load the plate into a plate reader and record the OD600 value for every well, including the growth control and sterility control.
3. <a id="3d6d65dd82be8073b0a6c6330f51f1db" />**Data analysis**: Subtract the sterility control OD600 (background) from each well. Plot OD600 versus antibiotic concentration (log scale on the x-axis) for each strain. Determine the MIC as the lowest concentration where no visible turbidity/growth occurs — this can be done visually or by fitting the curve with a Gompertz model for a more precise value.
