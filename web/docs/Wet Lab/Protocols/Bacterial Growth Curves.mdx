# <a id="3fcd65dd82be8078a374f5c177daf9fd" />Purpose

<a id="3fcd65dd82be804099d1e7e1d6bba0af" />This protocol measures the growth of bacteria over time using spectrophotometric measurements of culture density. We outline how to automate the growth curve measurement process using the BMG PHERAstar FSX microplate reader.

<a id="3fcd65dd82be80508b35c61e7a47876f" />This experiment will produce a curve that can be used to determine the rate of growth of an organism. Additionally, these procedures can be adapted to investigate the metabolic burden associated with reporter plasmids in transformed strains by comparing with the growth kinetics of the wild type.

# <a id="3fcd65dd82be808d85e0fff0590d84a3" />Methods

### <a id="3fcd65dd82be8094960ad096c824ea26" />Day 1-2: Streak and Starter

1. <a id="3fcd65dd82be807cb075d913a6e0c2d0" />Streak each strain of *E. coli* from glycerol stocks onto the appropriate LB agar plates (+/- antibiotics). Incubate overnight at 37ºC.
2. <a id="3fcd65dd82be8091b775ee28fea1e1cd" />Pick 3 colonies per strain, inoculate into separate tubes w/ 3 mL of LB media (+/- antibiotics). Incubate overnight at 37˚C, shaking at 220 rpm.

### <a id="3fcd65dd82be803ca316ca12d99e1a23" />Day 3: Plating & Readout

1. <a id="3fcd65dd82be8005a0cff2ce86258539" />Measure the OD600 of each culture. Dilute all cultures to an OD600 of 0.02 using LB media (± antibiotics).
2. <a id="3fcd65dd82be8017a3fcf7d7dbceeeaf" />In a 96-well plate, dispense 200 µL of DI water in the outermost wells to prevent evaporation.
3. <a id="3fcd65dd82be80419d84ef452a935494" />Dispense 200 µL of culture in the innermost wells.
4. <a id="3fcd65dd82be80e38d91e54f6fabdfa3" />Incubate the plate at 37˚C in the Cytomat Incubator for a total of 24 hours. Record OD600 using the BMG PHERAstar FSX microplate reader every 30-60 minutes.
   - <a id="3fcd65dd82be8035ab88c559bf2da1f4" />If simultaneously measuring fluorescence for reporter strains, use a black-bottom 96-well plate.
