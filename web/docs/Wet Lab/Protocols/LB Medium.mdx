# <a id="3fcd65dd82be807395acc4a30e678716" />Purpose

<a id="3fcd65dd82be80dca475de73be539124" />Prepare Luria-Bertani (LB) medium for growth of *E. coli* strains.

# <a id="3fcd65dd82be800bb639ce0c0e56137a" />Procedure

1. <a id="3fcd65dd82be80ddae49c55038394600" />To make 1000 ml of LB, fill up a glass media bottle with Milli-Q water to half its volume. Weigh out and add the the following reagents:
   <a id="3fcd65dd82be80339774f763932460a5" />
   |                                                                    |        |                           |
   | ------------------------------------------------------------------ | ------ | ------------------------- |
   | <a id="3fcd65dd82be80dda4ebe099f10fdfc4" />Component               | Amount | Final concentration       |
   | <a id="3fcd65dd82be8072b5c9d7632be11ff4" />LB                      | 25 g   | 25g/L                     |
   | <a id="3fcd65dd82be8002831bc94aa3031d17" />Agar (for solid medium) | 15 g   | 15g/L                     |
   | <a id="3fcd65dd82be8081a0bcce077c0263bb" />Antibiotic              | 1 mL   | \~1/1000th original conc. |
2. <a id="3fcd65dd82be80bb9ec1ca6ae3063621" />Mix well to dissolve all components, using heat and a stir bar as needed. Top up to 1000 ml with Milli-Q water.
3. <a id="3fcd65dd82be80878c1be30df1d9a96f" />Cap loosely the bottle and apply autoclave tape.
4. <a id="3fcd65dd82be8044ae80f8ef314e2f25" />Sterilize the media by autoclaving using in-house protocol LIQUID20 (121°C for 20 minutes)
5. <a id="3fcd65dd82be80d192dae661864ab5be" />After autoclaving, wait until cooled, then tighten the cap.
   - <a id="3fcd65dd82be803690bfe97630402edd" />Note: If you notice that there is pressure build-up, loosen the cap and cool the bottle before re-tightening the cap.
6. <a id="3fcd65dd82be8009964cfb1a292d8a76" />Add antibiotics only after the autoclaved solution returned to room temperature.
7. <a id="3fcd65dd82be803a97e3cd8f40020984" />Store in a cool, dry place at room temperature.
