# <a id="3fcd65dd82be80829b7bc6c782ae49df" />Purpose

<a id="3fcd65dd82be807d8217ecce3548015d" />This protocol outlines a method to determine the antibiotic concentration range is produces a dose-dependent GFP expression response from a biosensor reporter strain.

# <a id="3fcd65dd82be807dbc49dda1f2a38025" />Materials

- <a id="3fcd65dd82be805fb54afc315d726aec" />Antibiotics of interest
- <a id="3fcd65dd82be804e8c70f2d5413c3f74" />MilliQ Water
- <a id="3fcd65dd82be80579510cfffbf6963b7" />0.2 µm sterile filter
- <a id="3fcd65dd82be80718ec1c4b9e4dbedee" />LB-Cm media (17 mg/L)
- <a id="3fcd65dd82be80edae5bf646d4c22100" />RecA and CpxP biosensor strains (containing Cm selection marker)
- <a id="3fcd65dd82be8037ab65dd1589cdf02e" />Opaque-wall 96-well plates, flat bottom
- <a id="3fcd65dd82be8075bcccce5cadd4a4dc" />Microplate reader

# <a id="3fcd65dd82be80aeada3f94d6e3ed211" />Methods

## <a id="3fcd65dd82be80d59a34dc87ec2fc689" />Day 1: Culture Inoculations

1. <a id="3fcd65dd82be804ea5dbe336c3ae7ddc" />Inoculate 10 mL of LB-Cm from glycerol stocks of the bacterial strains.
2. <a id="3fcd65dd82be80029a58dafd82e5b26b" />Incubate overnight at 37˚C, shaking at 220 rpm.

## <a id="3fcd65dd82be80088d9ac5063db09a87" />Day 2: Plating and Readout

1. <a id="3fcd65dd82be80c19d80e58e53763943" />**Prepare antibiotics:** reconstituting in MilliQ water at the appropriate concentration. Sterile filter the stock solutions through a 0.2 µm filter.
2. <a id="3fcd65dd82be80acb757d930f46713a8" />**Prepare the working stock**: Adding the appropriate volume of antibiotics into the LB-Cm media. The concentration of this antibiotic-containing media should be 2x the highest concentration.
3. <a id="3fcd65dd82be80608843e0e3ba4d92ce" />**Prepare the inoculum**: Obtain the overnight culture and mix thoroughly. Read OD600 of the cultures. Dilute to an OD600 value of 0.2 in LB-Cm.
4. <a id="3fcd65dd82be80feaf17ec62aa158f80" />**Prepare the plate**:
   1. <a id="3fcd65dd82be80bfb1aec8fdf526fc92" />For the outermost wells, dispense 200 µL of sterile water
   2. <a id="3fcd65dd82be8001a0d1c791d5c7efa3" />Dispense 100 µL of LB-Cm into all interior wells except column 2 (cols 3-11, rows B-G)
   3. <a id="3fcd65dd82be80828e3df234455a2c57" />Dispense an additional 100 uL LB-Cm to the sterility well (blank media control, G11)
   4. <a id="3fcd65dd82be80bcbc83ee47f25e1d70" />Dispense 200 µL of the 2x antibiotic media into column 2. Mix throughly, then transfer 100 µL of mixture into the next column to the right. Repeat until column 10. Discard 100 µL from column 10
   5. <a id="3fcd65dd82be80249d7dd87d44343ad7" />Repeat steps 4d for all rows
   6. <a id="3fcd65dd82be8029b3b0fc9331eb1605" />Except for the media blank and moat wells, add 100 µL of inoculum to interior wells
5. <a id="3fcd65dd82be8048b5d5fef97c9a57e0" />**Initial Readout**: Read the OD600 and fluorescence of the plates immediately. After reading, return the plates to a 37˚C incubator.
6. <a id="3fcd65dd82be808d99e6ccee42e3d92d" />Repeat this reading at 30 min, 1 h, 2 h, 4 h and 8 h.
