# <a id="3fcd65dd82be8037bd3acda833095888" />Purpose

<a id="3fcd65dd82be807eb6e9f429b5f931db" />This protocol outlines a method for determining minimum inhibitory concentration (MIC) ranges for a bacterial strain using spectrophotometric measurements of bacterial density.

# <a id="3fcd65dd82be80e19043cb6fead4eb8d" />Materials

- <a id="3fcd65dd82be806eb0d8d051c1901397" />0.2 µm sterile filter and syringe
- <a id="3fcd65dd82be800fba86ea6fa141a42e" />Antibiotics
- <a id="3fcd65dd82be802eb6dbffc0023bb3ca" />MilliQ water
- <a id="3fcd65dd82be80dbad63eaaad227a8a7" />Glycerol stock of bacterial strain
- <a id="3fcd65dd82be803f8ad8f32ba4d65ea9" />Broth (e.g., LB for WT EPI300 *E. coli*, LB-Cm for transformed biosensor strains)
- <a id="3fcd65dd82be8036b387c3e01196a306" />Cuvettes
- <a id="3fcd65dd82be80e29c7ded7156c3b5ed" />Spectrophotometer
- <a id="3fcd65dd82be808b9b7bcb4d9ece27dd" />Opaque-wall 96-well microplate (flat-bottom, sterile)
- <a id="3fcd65dd82be803fbcc0efe48094e75b" />Multichannel pipette and reservoir
- <a id="3fcd65dd82be804b8055fc0340cd5706" />Microplate reader

# <a id="3fcd65dd82be809ba1b0eeda1ad2d741" />Method

## <a id="3fcd65dd82be8049b81fc8142d9bac9b" />Day 1: Preparation of Inoculum & antibiotics

1. <a id="3fcd65dd82be8026a2c2f08d8d0f6f51" />Inoculate 10 mL of the appropriate broth from a glycerol stock of the bacterial strain.
2. <a id="3fcd65dd82be80f9a522f2ef18945e92" />Incubate the strain to mid-log phase (e.g., $OD_{600}$ values of 0.4–0.6) overnight at 37 ºC, shaking at 220 rpm.
3. <a id="3fcd65dd82be80fcbb1efccd5f4facbd" />Prepare antibiotic stocks.
   1. <a id="3fcd65dd82be806987bce1ddf8da24ae" />Dissolve antibiotic powder in MilliQ water at 2× the highest concentration to be tested.
   2. <a id="3fcd65dd82be80a7b368f908508ab7ed" />Sterile filter the stock solution through a 0.2 µM filter.
   3. <a id="3fcd65dd82be80ceb639ffe96c525fbc" />Check concentration range on literature MIC values for your strain, spanning at least several dilutions below and above that value.

## <a id="3fcd65dd82be807a9f61ef5d22c259af" />Day 2: Plating the Assay

1. <a id="3fcd65dd82be8075ba14d5fc97eb5eb8" />**Prepare the culture**: Measure the $OD_{600}$ of the culture and dilute to an $OD_{600}$ value of 0.1 using broth.
2. <a id="3fcd65dd82be80838525ebf6f916d586" />**Make the 2x antibiotic media**: Create a total of 10 mL by adding the appropriate volume of antibiotics into the broth media. The concentration of this antibiotic-containing media should be 2x the highest concentration.
3. <a id="3fcd65dd82be80b48675d5b8598c6a46" />**Steps 3-6 will be performed using a multichannel pipette, in triplicate**. Add 200 µL of broth to column 1. Add 100 µL of broth to columns 3-12, leaving column 2 empty.

<a id="3fcd65dd82be8001b104ff36b750b9ea" />

|                                                        |                                                              |
| ------------------------------------------------------ | ------------------------------------------------------------ |
| <a id="3fcd65dd82be80ddbab6cae693f0d048" />**Columns** | **Contents**                                                 |
| <a id="3fcd65dd82be80adaa83d10225fcbcac" />1           | Sterility control or blank control (broth only, no inoculum) |
| <a id="3fcd65dd82be80d6bcbcd4358b7f8360" />2–10        | Serial 2-fold dilution series of antibiotic                  |
| <a id="3fcd65dd82be80ea9698d7ff8c7d807c" />12          | Untreated control (broth + inoculum, no antibiotic)          |

1. <a id="3fcd65dd82be806a8d16d29191675452" />**Perform the serial dilution:** Add 200 µL of the 2× antibiotic media to column 2. Using a multichannel pipette, mix and transfer 100 µL from column 2 into column 3. Mix, then transfer 100 µL from column 3 into column 4, and continue this pattern down to column 11. After mixing column 11, remove 100 µL and discard into waste so that all wells have an equal volume. Do not add any antibioitc media to column 12 (unstimulated control).
2. <a id="3fcd65dd82be8010a7a5e29d797d8e51" />**Inoculate the plate**: Add 100 µL of the diluted culture to each well in columns 2–12. Do not add inoculum to column 1 (blank control).
3. <a id="3fcd65dd82be80de86a0ee5bcfc6c48f" />Measure initial $OD_{600}$ of the plate for the t = 0 minutes time point.
4. <a id="3fcd65dd82be80a18062c4d21344157a" />Incubate the plate at 37°C for 16-24 hours.

## <a id="3fcd65dd82be8085af93db88970b9553" />Day 3: Read the plate and Determine MIC

1. <a id="3fcd65dd82be800187fcdc109b1ac1ba" />**Measure** $OD_{600}$: Load the plate into a microplate reader and record the $OD_{600}$ value for each well, including the growth control and sterility control.
2. <a id="3fcd65dd82be807487efe7671e164f7c" />**Data analysis**:
   1. <a id="3fcd65dd82be80b09288c19bdf1594ce" />Subtract the sterility control $OD_{600}$ (background) from each well.
   2. <a id="3fcd65dd82be80768302c6fb9dc29e9c" />Divide the normalized $OD_{600}$ values by the t = 0 minutes measurements. This obtains a ∆$OD_{600}$ value.
   3. <a id="3fcd65dd82be80649fa8e769b4d86489" />Plot ∆$OD_{600}$ versus antibiotic concentration for each strain.
3. <a id="3fcd65dd82be8044a8dfce7338d17749" />**Data interpretation**:
   1. <a id="3fcd65dd82be800aae87d9aa8f43577c" />When ∆$OD_{600}$ ≤ 0, bacterial growth is completely inhibited. This indicates the maximum value of the MIC range.
   2. <a id="3fcd65dd82be802e9d66d3ab5a0ff057" />When ∆$OD_{600}$ approaches 0 (e.g., 0—0.05), bacterial growth is slightly inhibited. This indicates the minimum value of the MIC range.
