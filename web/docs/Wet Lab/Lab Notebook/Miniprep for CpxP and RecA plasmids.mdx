# <a id="388d65dd82be8066afd6fcf7064b21a3" />Purpose

<a id="388d65dd82be804e9288fe78344e4ca9" />Miniprep the liquid cultures of the recA or CpxP plasmid-containing *E. coli*, and send the plasmids for sequencing.

# <a id="388d65dd82be80c8bb49e8a2d126a18f" />Materials & Methods

<a id="388d65dd82be809eaa5ce83ccec1d304" /><u>Materials</u>

- <a id="3a0d65dd82be80b48511c76a623a2ead" />NEB Monarch® Plasmid Miniprep Kit
- <a id="3a0d65dd82be80da88bff672e5c7bb4b" />NanoDrop 1000 Spectrophotometer
- <a id="3a0d65dd82be80f6b03ed60ff07c231c" />Plasmidsaurus Full Plasmid Sequencing

<br id="388d65dd82be80e2805de316b6132e6a" />

<a id="388d65dd82be80b0a05ac1ec7f9f0f46" />**Miniprep is based on the** [**manufacturer’s instructions**](https://www.neb.com/en-ca/protocols/monarch-plasmid-dna-miniprep-kit-protocol-t1010)**:**

1. <a id="388d65dd82be80deb353eb7d2352ca34" />200 uL RNAse buffer
2. <a id="388d65dd82be80c7a5ebc8e28a8057de" />200 uL Lysis buffer
   1. <a id="388d65dd82be809a8296c3e9d71f0e51" />invert the tube 5-6 times
   2. <a id="388d65dd82be8084b008e20b25189f11" />Wait 1 minute
3. <a id="388d65dd82be80e7bd98f169cd30039f" />400 uL Neutralization buffer
   1. <a id="388d65dd82be80e9bf3ceb126ad9da86" />invert the tube 5-6 times
   2. <a id="388d65dd82be805f8a24c787f347ed6c" />Wait 2 minutes
4. <a id="388d65dd82be80eb8c31f3d25ef783bb" />Spin at 10000 x g for 5 minutes
5. <a id="388d65dd82be801e94b9cd0e5ac2ae12" />800 uL of supernatant into the column in a collection tube
6. <a id="388d65dd82be80c0b472eaae820b0714" />Spin at 1000 x g for 5 minutes
   1. <a id="388d65dd82be80b380a7d7010de61077" />Pour the flow-through into the column again and re-spin at 1000 x g for 5 minutes
   2. <a id="388d65dd82be8031a4a8f17241504fe7" />Discard flow-through
7. <a id="388d65dd82be8040a9d9d5d3f0b03d90" />200 uL of wash 1
8. <a id="388d65dd82be808eaba6c76ee3ab28d1" />Spin at 10000 x g for 1 minute
9. <a id="388d65dd82be8025b7d3c75c100e0dd2" />400 uL of wash 2
10. <a id="388d65dd82be80378c5df9bbf7479925" />Spin at 10000 x g for 1 minute
11. <a id="388d65dd82be8042a30de2ed550a9a3c" />Discard the collection tube and place the miniprep column in a clean microcentrifuge tube
12. <a id="388d65dd82be806c985bd2e6b3cb4882" />45 uL of pre-warmed H2O
    1. <a id="388d65dd82be80c4a282f7d4df6c6a21" />incubate at room temperature for 3-4 minutes
    2. <a id="388d65dd82be800ea75cc33b358b4448" />Spin at 10000 x g for 1 minute

<br id="388d65dd82be8083a68ed586e0ae2bb5" />

<a id="388d65dd82be8015ac26dcbe5d8c46ed" />**Nanodrop-1000 Spectrophotometer**

1. <a id="388d65dd82be80e2a9bbd7c4ce685412" />Measure 2 uL of eluted plasmid using the Nanodrop-1000
2. <a id="388d65dd82be8003b5adcba129c3f9a8" />Record DNA concentration (ng/uL) and 260/280 ratio

<a id="388d65dd82be80298706e9407500fe6e" />Note: the ideal 260/280 ratio is 1.80.

<br id="388d65dd82be80a0afe2f28ae49e7924" />

<a id="388d65dd82be80a5bf24de6900b234be" />**Plasmidsaurus full-plasmid sequencing is based on Plasmidsaurus instructions:**

1. <a id="388d65dd82be805db53ee6f86c1728bb" />Add 500 ng of DNA into a PCR tube
2. <a id="388d65dd82be80199edfe0a89fa9bf84" />Top up to 15 uL total volume with H2O
3. <a id="388d65dd82be8003822ef620b7c04e0b" />Request sequencing using the Plasmidsaurus website and drop off the sample at a designated pick-up location (ie, SBME)

# <a id="388d65dd82be80f98e6be5c49af34924" />Results

<a id="388d65dd82be8063864dfcff9bd0eedf" />Miniprep yielded high concentrations of DNA for both recA and CpxP plasmids.

- <a id="388d65dd82be80c79e57c8bd828502f5" />RecA plasmid: **99.8 ng/uL** and **260/280: 1.95**

- <a id="388d65dd82be80fa94a8e5a9c1023e94" />recA plasmid: 100% matched to template DNA

  - <a id="388d65dd82be80358346fb8f03231164" />Second mutation → silent mutation on Cm selection gene → no effect

    - <a id="388d65dd82be80f8bc16d19d370d75aa" />The colonies are still able to grow on antibiotic-containing plates
    - <a id="388d65dd82be8093a912d614609ce914" />The CpxP promoter and sfGFP gene are unaffected → should be fully functional!
