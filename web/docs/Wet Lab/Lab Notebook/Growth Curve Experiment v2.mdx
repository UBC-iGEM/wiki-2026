## <a id="3cbd65dd82be80f1b07adb561dc8cbfe" />Procedure

### <a id="3cbd65dd82be8030b711dcc718e03bc8" />Day 1 - Streaking

1. <a id="3cbd65dd82be80adb1cedbbe4f672641" />Streak each strain and grow overnight at 37ºC
   1. <a id="3cbd65dd82be804ea697ddcc194025d7" />Use LB agar plates for strain 1, LB-Cm plates for strains 2-4
2. <a id="3cbd65dd82be80bab5a1fb2220f79b5b" />Additionally, streak media from bottles on LB agar plates to check for sterility

### <a id="3cbd65dd82be80f985f1de66b7f9ea80" />Day 2 - Starter Cultures

1. <a id="3cbd65dd82be80509d26e57f708e6c86" />Pick 3 colonies per strain, inoculate into separate tubes w/ 3mL of media each and grow overnight at 37C , 200rpm
   1. <a id="3cbd65dd82be8053a339dca76dac423d" />Use LB for strain 1, LB-Cm for strains 2-4
