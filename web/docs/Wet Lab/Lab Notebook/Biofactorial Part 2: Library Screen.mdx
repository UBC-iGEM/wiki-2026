# <a id="3fdd65dd82be80d38a87eacae077ff63" />Objective

<a id="400d65dd82be80e0969cc329bc0cd487" />Using the identified sub-inhibitory concentrations, we will now expose the entire promoter library against the antibiotics, collecting $OD_{600}$ and GFP fluorescence readouts over 8 hours.

# <a id="3fdd65dd82be809e9dc5f72f86259b51" />Experiment

## <a id="3fdd65dd82be80a5a5d0c21e38716980" />Plate Plan

<a id="3fdd65dd82be80a29201d72aaad3c17b" />Prepare 30 destination plates:

<a id="3fdd65dd82be803eadc3fa6844b7f53c" />

| <a id="3fdd65dd82be801ca54fc68b72490ebe" />Plate type             | Number |
| ----------------------------------------------------------------- | ------ |
| <a id="3fdd65dd82be80cdbd47df1543347306" />Amoxicillin treatment  | 6      |
| <a id="3fdd65dd82be8061bd0bed9c88b3f447" />Cephalexin treatment   | 6      |
| <a id="3fdd65dd82be805aadbffb22e4541a85" />Gentamicin treatment   | 6      |
| <a id="3fdd65dd82be803fbd26eeae67415089" />Tobramycin treatment   | 6      |
| <a id="3fdd65dd82be803381fbe09b8be85bf2" />No-antibiotic controls | 6      |
| <a id="3fdd65dd82be80d8a996ee94cc6d2036" />Total                  | 30     |

<a id="3fdd65dd82be80648469f08977e34afe" />Each set of **five** destination plates corresponds to one library plate: four antibiotic conditions and one matching no antibiotic control.

## <a id="3fdd65dd82be809596d3cdc063bd81f5" />Equipment

- <a id="3fdd65dd82be80a2a9ecf08ea6a81b59" />Liquid Handler Pinning Machine
- <a id="3ffd65dd82be8053b3d4fdcfffe40dcd" />Echo Acoustic Liquid Handler
- <a id="3fdd65dd82be80cbac71c1a803658cc1" />Wellmate for LB
- <a id="3fdd65dd82be8092abbbef1f8b289878" />30 384-well destination plates
- <a id="3fdd65dd82be800a9a5ad389945b3cd4" />6 384-well library source plates
- <a id="3fdd65dd82be80a38dd7fd68322bf224" />4 antibiotic stocks, at concentrations from Experiment 1
- <a id="3fdd65dd82be80ca896adffd115f5087" />LB broth
- <a id="3fdd65dd82be80d58cd8d6a3c8179608" />Access Workstation for $OD_{600}$ and GFP measurements
- <a id="3fdd65dd82be80ae91d3c3366421c8cc" />Library plate-to-plate transfer equipment: (unsure equipment)

# <a id="3fdd65dd82be8035a37ae66e37620616" />Procedure

1. <a id="3fdd65dd82be806bad48e4ca27c5ad90" />Prepare one concentration per antibiotic from Experiment 1:
   - <a id="3ffd65dd82be80adbf5ae45647a0b999" />Amoxicilin: 2 μg/mL
   - <a id="3ffd65dd82be8056950ceff973ccd56d" />Cephalexin: 1 μg/mL
   - <a id="3ffd65dd82be804ca253c0d89e18e356" />Gentamicin: 1 μg/mL
   - <a id="3ffd65dd82be80a0adddd21a010e94df" />Tobramycin: 1 μg/mL
2. <a id="3fdd65dd82be80c6bf88e79d0525e7b5" />Label destination plates by library plate and AB.
3. <a id="3fdd65dd82be80e29b71fd695cf27392" />Use the Echo Acoustic Liquid Handler to dispense the selected antibiotic concentrations into all 384 wells of the six corresponding treatment plates. Do not add antibiotic to the six control plates.
4. <a id="3fdd65dd82be80e8b95bfa6ece802b62" />Copy each library plate to its five matching destination plates keeping the same well positions. Dispense 70 nL into each well using a Liquid Handler Pinning Machine.
5. <a id="3fdd65dd82be80329038ff064f49b53b" />Add the same volume of LB medium to every well.
6. <a id="3fdd65dd82be808d9efefe2fde6ce435" />Incubate and measure $OD_{600}$ and GFP fluorescence using the same read timing as Experiment 1.
7. <a id="3fdd65dd82be807f9b76d1175aa4f903" />Compare each clone’s growth and fluorescence under each antibiotic condition against its control.
