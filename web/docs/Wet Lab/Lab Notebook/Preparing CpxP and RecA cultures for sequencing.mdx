# <a id="388d65dd82be80a9b76bf7b630d612eb" />Purpose

<a id="388d65dd82be802a89dbfd88b8c1e13b" />Pick a single colony and grow it up in liquid culture to miniprep and send it for sequencing.

# <a id="388d65dd82be80eba986f4d38481b947" />Materials & Methods

<a id="388d65dd82be8057beddf00cb0c2ffbe" /><u>Materials</u>

- <a id="3a0d65dd82be80ffa5e7cea6c484952a" />Transformed DH5a single colonies from [Transformation of CpxP/RecA into DH5a](/ubc-vancouver/wet-lab/lab-notebook/transformation-of-cpxp/reca-into-dh5a)
- <a id="3a0d65dd82be80b8a732ed199118b7b0" />5 mL of LB media (per single colony) containing 17 mg/L of Chloramphenicol (Cm) antibiotic

<a id="3a0d65dd82be803899cbddfdccdbe41c" /><u>Methods</u>

1. <a id="388d65dd82be8009baa6c85716e7f910" />Circle 1-2 single isolated colonies.
2. <a id="388d65dd82be80759fe9da6833d387e4" />Dip the colonies in their separate tubes of 5 mL Cm containing media.
3. <a id="388d65dd82be8053abe9d512d4fe8222" />Incubate the colonies at 37°C while shaking overnight.

# <a id="388d65dd82be80348d30e612b51f4eff" />Results

<a id="388d65dd82be80beb01fd1a2faf641c5" />The colonies successfully grew overnight in the liquid culture.

# <a id="388d65dd82be808b915acfc2c31e96ba" />Summary

<a id="388d65dd82be803e8783c78d65c74ab3" />Single colonies of *recA* or CpxP plasmid-containing bacteria were successfully inoculated and grew in liquid culture overnight.
