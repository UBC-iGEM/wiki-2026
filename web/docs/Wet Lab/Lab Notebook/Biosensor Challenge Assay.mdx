# <a id="3e0d65dd82be804ca522d5976292e830" />Background

## <a id="3e0d65dd82be8051859ecba44f508c46" />Objective

<Callout icon="🗣">
  <a id="3e0d65dd82be8067902ac2c1836c4dc9" />What is the maximum antibiotic concentration which the biosensors can tolerate?
</Callout>

<a id="3e0d65dd82be80eeb241e72797cc461a" />We will repeat repurpose the assay developed in [WT Biosensor MIC Titration v1](/ubc-vancouver/wet-lab/lab-notebook/wt-biosensor-mic-titration-v1) to determine an MIC value for the biosensors across all 4 antibiotics.

## <a id="3e0d65dd82be801594b6d2626802a0e7" />Procedure

### <a id="3e0d65dd82be8008b736dc257db913a4" />Day 1  - Prep Cultures + AB stocks + Media & Water

<a id="3e0d65dd82be8068bf00e4dbe7ca867a" />**<u>Prepare LB-Cm Media</u>**

1. <a id="3e0d65dd82be80a0a5f3f12da09b9335" />Prep 500mL LB Cm-Miller.

<a id="3e0d65dd82be800e8098d7fcc7ee1043" />**<u>Prepare Sterile Water</u>**

1. <a id="3e0d65dd82be8029be22dfb5a22874ac" />Fill 500mL bottle with MilliQ water, loosely cap and place autoclave tape
2. <a id="3e0d65dd82be80c2a0dddef3c3794b21" />Run with LB Media in autoclave on LIQUID20

<a id="3e0d65dd82be8009a7a1ef39f2d522a3" />**<u>Culture Prep</u>**

1. <a id="3e0d65dd82be80b091dec40ee2b6923b" />Inoculate 2 culture tubes with RecA and CpxP respectively in \~5-7mL of Lb Cm Media
2. <a id="3e0d65dd82be8071aecac8c88cd4e090" />Place culture tube in 37C room, 200-250rpm, over night

<a id="3e0d65dd82be80c6ab84d0fd13c78a8b" />

### <a id="3e0d65dd82be806ba220c67e1ebee8fc" />Day 2 - Plate Preparation

<a id="3e0d65dd82be80c98fb7e9e6e60762b5" />**<u>Prepare Gentamicin and Tobramycin Stocks</u>**

1. <a id="3e0d65dd82be80f5afc8cd6e36d3da8a" />Read potency on antibiotics. Calculate amount needed to create a 1 mg/mL master stock of 15 mL
2. <a id="3e0d65dd82be8054b8fbd836953b1cdf" />Dissolve in water, vortex, and filter
3. <a id="3e0d65dd82be806398a8d03ca79f573c" />Aliquot 3mL into 5mL tubes, label with date and identity
4. <a id="3e0d65dd82be800e9c51dac4ee169bbc" />Store in -20C

<Callout icon="🥼">
  <a id="3e0d65dd82be801ca409e5977fab6263" />For gentamicin, the target weight for 1mg/mL in 15mL is:

  <a id="3e0d65dd82be80ec8cd8fae0f9c9e4f8" />$15 mL \cdot \frac{1mg}{1mL} \cdot \frac{1mg}{0.6mg} = 25mg$

  <a id="3e0d65dd82be8081bfa6dbfeb120dd0c" />Actual weight was 23.5 mg → 14.1 mg active, 14.1 mL MilliQ H2O added

  <a id="3e0d65dd82be80209323c07e6993b12a" />For tobramycin, the target weight for 1mg/mL in 15mL is:

  <a id="3e0d65dd82be80f2b8bed28223b3284b" />$15 mL \cdot \frac{1mg}{1mL} \cdot \frac{1mg}{0.972mg} = 15.42mg$

  <a id="3e0d65dd82be802a93aed22e1952b9e7" />Actual: 27.9 mg → 27.1 mg active, 27.1 mL MilliQ H2O added

  <br id="3e0d65dd82be803ebb83fb357fcbe025" />
</Callout>

<a id="3e0d65dd82be80e98473c084f507ddd3" />**<u>Prepare Amoxicillin Stock</u>**

1. <a id="3e0d65dd82be80a9865ce5474cc0f9bc" />Read potency on antibiotic. Calculate amount needed to create a 1 mg/mL master stock of 15 mL
2. <a id="3e0d65dd82be80e8b8fdc308025ffd07" />Dissolve in water, vortex, and filter
3. <a id="3e0d65dd82be809c961edb25394e27c3" />Aliquot 3mL into 5mL tubes, label with date and identity
4. <a id="3e0d65dd82be80c58fffe99c2d6adbb4" />Store in -20C

<Callout icon="🥼">
  <a id="3e0d65dd82be808da5fad66d881ff85b" />For amoxicillin, the target weight for 1mg/mL in 15mL is:

  <a id="3e0d65dd82be80eda1b1c65fe6989520" />$15 mL \cdot \frac{1mg}{1mL} \cdot \frac{1mg}{0.9mg} = 16.67mg$

  <a id="3e0d65dd82be8013b888f9c211b60ce4" />Actual: 17.1 mg → 15.39 mg active, 15.39 mL MilliQ H2O added

  <br id="3e0d65dd82be80fa9744ece1b28e1aef" />
</Callout>

<a id="3e0d65dd82be80839c8cc439b57cb60b" />**<u>Working Stock Preparation</u>**

1. <a id="3e0d65dd82be80939455f9f8aa0cef95" />Into Eppendorf tubes, prepare the highest concentration of the antibiotics according to the following dilutions.
   1. <a id="3e0d65dd82be8087ae5bf277b3641590" />These are 2x concentrations

| <a id="3e0d65dd82be80b98472c4a3aa3b2089" />Gentamicin  | 32             | 32              | 968         |

- <a id="3e0d65dd82be8000a620eaff6298cf48" />Growth control is no antibiotic to compare against
- <a id="3e0d65dd82be80ebaaadf4ebf55d3cb9" />Sterility control is the media blank

<br id="3e0d65dd82be80e8b0c8f0d9b00a58af" />

1. <a id="3e0d65dd82be8032bd62c0c07a6d0a2c" />For each moat well, dispense 200uL sterile water
2. <a id="3e0d65dd82be80789440cbcbdb178782" />Dispense 100uL LB into all interior wells except column 2 (cols 3-11, rows B-G)
3. <a id="3e0d65dd82be808d8114fd354cb95115" />Dispense an additional 100uL LB to the sterility well (G11)
4. <a id="3e0d65dd82be8052a8e0f34b03c230b1" />Dispense 200uL of the working stock into column 2
5. <a id="3e0d65dd82be80f99b4fd5dcf57bd158" />Mix throughly (4-5 up-downs), then pipette 100uL into the next column to the right
6. <a id="3e0d65dd82be80918e5ec427e0dd386f" />Repeat step 4 until you reach column 10, discard 100uL from column 10
   1. <a id="3e0d65dd82be80c5965cf093b3fedecf" />You should have 100uL in each well, with 2x the concentration of antibiotic
7. <a id="3e0d65dd82be80ffa037c1411798c0e0" />Repeat steps 4-6 for all rows
8. <a id="3e0d65dd82be80f89e8aca788b0c904a" />When you are done with a plate, remember to place the lid back on

<a id="3e0d65dd82be80c39859fa176cae7713" />**<u>Inoculum Preparation</u>**

1. <a id="3e0d65dd82be8050b7d0c447608b84d7" />Obtain the overnight culture and mix throughly
2. <a id="3e0d65dd82be80a89330d4fe5690bf39" />In a 1cm cuvette, add 900 uL of culture and read OD 600
   1. <a id="3e0d65dd82be806ba77bc4f5b17e4d0f" />Use plain LB media as a blank
3. <a id="3e0d65dd82be809f8ba7de97b9effd04" />Adjust the suspension with LB to a target OD600 of 0.2
4. <a id="3e0d65dd82be8035b47dea1c8fa49595" />Invert the tube to mix

<a id="3e0d65dd82be80e5b542d59fe2228e0c" />**<u>Plate Addition</u>**

1. <a id="3e0d65dd82be808c9a46f5fe7909802d" />Except for the sterility control well, add 100uL of the prepared inoculum to all interior (non-moat) wells
