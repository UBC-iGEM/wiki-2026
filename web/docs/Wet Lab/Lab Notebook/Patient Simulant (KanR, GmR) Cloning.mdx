# <a id="3fdd65dd82be805999a6e5c1d06b6b34" />Purpose

<a id="3fdd65dd82be80c5999fca26b34e6c3e" />This entry describes HiFi assembly of KanR and GmR patient simulant plasmids, which were then transformed into *E. coli Epi300* strain to produce KanR- and GmR-expressing patient simulants. HiFi assembly protocol taken from NEB.

# <a id="3fdd65dd82be80c2865dc65094cdac0a" />Materials & Methods

<a id="3fdd65dd82be809e89c3e1151c6d50ae" />For a 2-3 fragment HiFi assembly at a 1:2 vector-insert ratio

<a id="3fdd65dd82be80f39329d70c47eda602" />using suggested min 0.03 pmol for total fragments

<a id="3fdd65dd82be8091b11ed82ced7ec84f" />(note MM is always 1/2 total rxn volume)

<a id="3fdd65dd82be80e8bdf0d626748470e5" />Volumes for Cpxp and recA were calculated based on stock concentrations of 10 ng/uL

<a id="3fdd65dd82be80efb1b9fc04cc8029ac" />

|                                                          |          |          |
| -------------------------------------------------------- | -------- | -------- |
| <a id="3fdd65dd82be806e9bf2f053426a28d8" />Plasmid Name  | KanR     | GmR      |
| <a id="3fdd65dd82be80d2a953e59876dc0afe" />Backbone (nt) | 1501     | 1501     |
| <a id="3fdd65dd82be80309e64dfae799733b4" />Insert (nt)   | 1469     | 1184     |
| <a id="3fdd65dd82be803e9ceaceaa7d0ca154" />Backbone      | 9.25 ng  | 9.25 ng  |
| <a id="3fdd65dd82be809c971ddf167f387ba9" />Insert mass   | 18.10 ng | 14.59 ng |
| <a id="3fdd65dd82be8069a483e2d65f6304af" />Vol Backbone  | 0.925 uL | 0.925 uL |
| <a id="3fdd65dd82be80f3affce3bb1037f1f0" />Vol Insert    | 1.81 uL  | 1.46 uL  |
| <a id="3fdd65dd82be80e5bc19c7b4d05fe3b5" />              |          |          |

<a id="3fdd65dd82be80c9bdadd5ce787f6d17" />Scale down to 6 uL by multiplying by 0.3 (6/20) (vol in uL)

<a id="3fdd65dd82be80339155d29c95804654" />

|                                                              |      |      |
| ------------------------------------------------------------ | ---- | ---- |
| <a id="3fdd65dd82be8024b282fdc83e11568b" />Content           | KanR | GmR  |
| <a id="3fdd65dd82be80a2bdded50d73629426" />Insert            | 0.54 | 0.44 |
| <a id="3fdd65dd82be800799d9d28600afcb35" />Backbone          | 0.28 | 0.28 |
| <a id="3fdd65dd82be80aeaa49f1cc99091787" />HiFi MM           | 3    | 3    |
| <a id="3fdd65dd82be80d39fe3fcae4f2036a2" />Nuclease free H2O | 2.18 | 2.28 |
| <a id="3fdd65dd82be80819388f9a938f439c4" />Total             | 6    | 6    |
| <a id="3fdd65dd82be8084b407f0a3427bd24c" />                  |      |      |

<a id="3fdd65dd82be803895b0f53aaffb757c" />Once all components for the HIFI Assembly were combined, the mixture was placed in the thermocycler.

<a id="3fdd65dd82be8097b0c3ef4fcb7a3182" />From NEB again thermocycle:

- <a id="3fdd65dd82be80218d64fa022c45aac3" />15 min at 50 deg C

<a id="3fdd65dd82be80519a73f080d766e4e2" />HIFI Assembly products were transformed via heat shock into DH5a:

1. <a id="3fdd65dd82be80c8bc97fa8d3caca2b2" />Mix 9 µL of chemically competent DH5a bacteria with 1 µL of cloned plasmid (recA or CpxP)
   1. <a id="3fdd65dd82be8037a906d2c3e66a3284" />pipette up and down to mix
2. <a id="3fdd65dd82be80bb84d4f01b281244c2" />Incubate on ice for 30 minutes
3. <a id="3fdd65dd82be801fae9ef9fcf3e033b2" />Heat shock at 42°C for 30 seconds
4. <a id="3fdd65dd82be80efb986f1cbf3421b7f" />Incubate on ice for 5 minutes
5. <a id="3fdd65dd82be809d8deff2329149a125" />Add 100 µL of SOC outgrowth medium and incubate at 37°C for 1 hour
6. <a id="3fdd65dd82be8044bd02cdf34507d243" />Plate 50 uL on each plate and incubate at 37°C overnight

<a id="3fdd65dd82be803c853cf204a50c8724" />Resulting single colonies were picked and grown in 5 mL of Cm-containing medium.

- <a id="3fdd65dd82be804bb1a6fce53af4710a" />Incubate the colonies at 37°C while shaking overnight.

<a id="3fdd65dd82be80068c47fefdb3ea0cc8" />Overnight liquid culture was miniprepped **based on the** [**manufacturer’s instructions**](https://www.neb.com/en-ca/protocols/monarch-plasmid-dna-miniprep-kit-protocol-t1010)

<a id="3fdd65dd82be8046b562ef22a8ea7ae6" />Resulting plasmids were sent for full plasmid sequencing via Plasmidsaurus

<a id="3fdd65dd82be80bca176f8917078a9e7" />Once sequencing validated the plasmids, they were transformed  into *E. coli* Epi300 strain via heatshock and plated on Cm plates

<a id="3fdd65dd82be8091bb60e98c2c2a137c" />Resulting single colonies were saved as glycerol stocks of patient simulants
