# <a id="3ead65dd82be80ca92cacf7efc8cf98e" />Background

## <a id="3ead65dd82be8084a8d5f3a17465c2c8" />Objective

<Callout icon="🗣">
  <a id="3ead65dd82be804da525d3156de22c05" />To determine whether frozen down antibiotics can be used/remain suitable for experimentation.
</Callout>

<a id="3ead65dd82be80ab8162c5f407160cd9" />We will reperform the [Biosensor Challenge Assay](/ubc-vancouver/wet-lab/lab-notebook/biosensor-challenge-assay) using antibiotics reconstituted a month ago but frozen in the -20C. Substantial deviation from the MIC ranges found would indicate a loss of potency.

## <a id="3ead65dd82be80b5af2beafb2ac04c28" />Variables

<a id="3ead65dd82be8028a5b8d0ad656ae308" />Independent:  Antibiotic Concentration

<a id="3ead65dd82be8071b4f5fd4e374ea58f" />Dependent: OD600

# <a id="3ead65dd82be80dbb205e4e01a4f5501" />Background

<a id="3ead65dd82be80088896f93b0f2564ca" />WT EPI300 will be exposed to a concentration range of each antibiotic using the same Biosensor Challenge Assay conditions used previously. The resulting OD600 values will be compared with the previously observed MIC ranges to assess whether the frozen stocks produce a similar response.

# <a id="3ead65dd82be801eb073c2fcfa9f2347" />Experiment

## <a id="3ead65dd82be8077a670c4dd315f004f" />Procedure

### <a id="3ead65dd82be80e8baa3fab54732a0f7" />Day 1  - Prep Cultures + AB stocks + Media & Water

<a id="3ead65dd82be800182e1d1bad32693a2" />**<u>Prepare LB-Cm Media</u>**

1. <a id="3ead65dd82be80398528f676d9b9fd2c" />Prep 500mL LB Cm-Miller

<a id="3ead65dd82be80f2b902fbbe9af4c725" />**<u>Prepare Sterile Water</u>**

1. <a id="3ead65dd82be80089bfde6b81a46ae7b" />Fill 500mL bottle with MilliQ water, loosely cap and place autoclave tape
2. <a id="3ead65dd82be80c48e9fc4169bb74e67" />Run with LB Media in autoclave on LIQUID20

<a id="3ead65dd82be801db86af87bc500b55e" />**<u>Culture Prep</u>**

1. <a id="3ead65dd82be80e08b81c757a1cd1599" />Inoculate 2 culture tubes with RecA and CpxP respectively in \~5-7mL of Lb Cm Media
2. <a id="3ead65dd82be8039bb38fb306167b000" />Place culture tube in 37C room, 200-250rpm, over night

### <a id="3ead65dd82be80d19dccf3a5ac157c01" />Day 2 - Plate Preparation

<a id="3ead65dd82be807596e9e30ac3b938c9" />**<u>Prepare Antibiotics from Frozen Stocks</u>**

1. <a id="3ead65dd82be804a80aad5473669d63a" />Retrieve frozen antibiotic stocks from -20 C (Gentamicin, Tobramycin, Amoxicillin).
2. <a id="3ead65dd82be808b83fcc6c65c57d49d" />Allow frozen antibiotic stocks to thaw at room temperature.
3. <a id="3ead65dd82be80cf98a6cb970ef727ee" />Use these thawed stocks for working stock preparation.

<a id="3ead65dd82be8064abffefe9ec0c6bc5" />**<u>Working Stock Preparation</u>**

1. <a id="3ead65dd82be80569240dc9a20643481" />Into Eppendorf tubes, prepare the highest concentration of the antibiotics according to the following dilutions.
   1. <a id="3ead65dd82be80c7989dcaf74484bfd9" />These are 2x concentrations

<a id="3ead65dd82be809aa20bc62fc814f38a" />

| <a id="3ead65dd82be8055a948fbde86eabfec" />Antibiotic  | Target (ug/mL) | Master Vol (uL) | LB Vol (uL) |
| ------------------------------------------------------ | -------------- | --------------- | ----------- |
| <a id="3ead65dd82be805c8b78eb47bd94887c" />Gentamicin  | 32             | 32              | 968         |
| <a id="3ead65dd82be80e0b57fefdd315766a7" />Tobramycin  | 32             | 32              | 968         |
| <a id="3ead65dd82be800594abd498ffe4d195" />Amoxicillin | 64             | 64              | 936         |

1. <a id="3ead65dd82be80a4868fe638e89a838a" />Vortex each tube

<a id="3ead65dd82be80eea486ef9d5342e919" />**<u>Plate Preparation</u>**

<a id="3ead65dd82be8004bb81ce583ee469ff" />The following plate layouts will be used

<a id="3ead65dd82be80809927fbb206c19e62" />`M` Water Moat         `G` Growth Control         `S` Sterility Control.         `1-9` Antibiotic

- <a id="3ead65dd82be80b69238c1637763469d" />The water moat is to create an evaporation buffer
- <a id="3ead65dd82be800db899ca17d1387aab" />Growth control is no antibiotic to compare against
- <a id="3ead65dd82be80f3814bdf206bfc606b" />Sterility control is the media blank

<br id="3ead65dd82be8017986ddb2889766fec" />

1. <a id="3ead65dd82be80a58200f23a3839c83d" />For each moat well, dispense 200uL sterile water
2. <a id="3ead65dd82be80048123faeedb32d832" />Dispense 100uL LB-Cm into all interior wells except column 2 (cols 3-11, rows B-G)
3. <a id="3ead65dd82be80be9c95d497f47fc603" />Dispense an additional 100uL LB to the sterility well (G11)
4. <a id="3ead65dd82be80709f40fb52188e5c26" />Dispense 200uL of the working stock into column 2
5. <a id="3ead65dd82be8053b4c3c8e317fdb437" />Mix throughly (4-5 up-downs), then pipette 100uL into the next column to the right
6. <a id="3ead65dd82be802b93b7e43a00fd2953" />Repeat step 4 until you reach column 10, discard 100uL from column 10
   1. <a id="3ead65dd82be807cafe4ded8198b19ab" />You should have 100uL in each well, with 2x the concentration of antibiotic
7. <a id="3ead65dd82be809abfeffd4bd1d4eae5" />Repeat steps 4-6 for all rows
8. <a id="3ead65dd82be8015a55ce003e0515aa1" />When you are done with a plate, remember to place the lid back on

<a id="3ead65dd82be80729b8cebac4e35a0c7" />**<u>Inoculum Preparation</u>**

1. <a id="3ead65dd82be80eba733ca84436993b0" />Obtain the overnight culture and mix throughly
2. <a id="3ead65dd82be80738b9fd2ac04af67c7" />In a 1cm cuvette, add 900 uL of culture and read OD 600
   1. <a id="3ead65dd82be80b38fc4c82107a61fec" />Use plain LB media as a blank
3. <a id="3ead65dd82be8035ba84e3946e297f88" />Adjust the suspension with LB to a target OD600 of 0.2
4. <a id="3ead65dd82be805892dbfa7d78eecf60" />Invert the tube to mix

<a id="3ead65dd82be80cf9c81e183fda16bb8" />**<u>Plate Addition</u>**

1. <a id="3ead65dd82be80fbae1ff3d231023dfe" />Except for the sterility control well, add 100uL of the prepared inoculum to all interior (non-moat) wells
