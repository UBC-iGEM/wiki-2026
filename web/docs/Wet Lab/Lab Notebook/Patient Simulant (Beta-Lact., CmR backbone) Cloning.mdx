# <a id="3fdd65dd82be80ffbc86f540e2fb308c" />Purpose

<a id="3fdd65dd82be8036bb95c27ad7f322c4" />This entry describes HiFi assembly of a β-lactamase patient simulant plasmid and a CmR control plasmid, which were then transformed into *E. coli* EPI300 strain to produce β-lactamase-resistant patient simulants and a CmR control strain. HiFi assembly protocol taken from NEB.

# <a id="3fdd65dd82be80809437eca09265a39b" />Materials & Methods

<a id="3fdd65dd82be805c9f16fa1c8f77d6d3" />For a 2-3 fragment HiFi assembly at a 1:2 vector-insert ratio

<a id="3fdd65dd82be80149432eb7f180a2702" />using suggested min 0.03 pmol for total fragments

<a id="3fdd65dd82be80a49e47e78ebcc7b1d9" />(note MM is always 1/2 total rxn volume)

<a id="3fdd65dd82be8063ba33fbaff1f95448" />Volumes for β-lactamase and CmR were calculated based on stock concentrations of 10 ng/µL

<a id="3fdd65dd82be80529d81d061c5ef3ee5" />

|                                                          |             |          |
| -------------------------------------------------------- | ----------- | -------- |
| <a id="e58bc0de366a4b31910b5911a100c3fc" />Plasmid Name  | β-Lactamase | CmR      |
| <a id="3fdd65dd82be80839603eb01a6941c67" />Backbone (nt) | 1501        | 1163     |
| <a id="3fdd65dd82be80ca86bee54fdbdd8cfc" />Insert (nt)   | 1514        | 951      |
| <a id="3fdd65dd82be808fb36be541defa4ea8" />Backbone      | 9.25 ng     | 7.16 ng  |
| <a id="3fdd65dd82be8002b04cf1d1bed62911" />Insert mass   | 18.65 ng    | 11.72 ng |
| <a id="ea5821d3a85f48148c705452e894e01b" />Vol Backbone  | 0.925 µL    | 0.716 µL |
| <a id="6b04cc74540a41599ac5e6a87f6b5728" />Vol Insert    | 1.87 µL     | 1.17 µL  |
| <a id="3fdd65dd82be80d6bcaaeff97b8113cb" />              |             |          |

<a id="3fdd65dd82be80e7bf62f82a39d8bcda" />Scale down to 6 µL by multiplying by 0.3 (6/20) (vol in µL)

<a id="3fdd65dd82be80978a60dfaa83d94cb6" />

|                                                              |      |      |
| ------------------------------------------------------------ | ---- | ---- |
| <a id="3fdd65dd82be80ba8806c4d926cc3477" />Content           | KanR | GmR  |
| <a id="3fdd65dd82be80ec986af169236cd5d7" />Insert            | 0.56 | 0.35 |
| <a id="3fdd65dd82be8075a07ee60f52c6c9e9" />Backbone          | 0.28 | 0.21 |
| <a id="3fdd65dd82be80128715ecc73d14e441" />HiFi MM           | 3    | 3    |
| <a id="3fdd65dd82be80b7b83fc9172d0ad5d0" />Nuclease free H2O | 2.16 | 2.44 |
| <a id="3fdd65dd82be806ba74bd6f9114f2ae0" />Total             | 6    | 6    |
| <a id="3fdd65dd82be80678a61d62dae517b42" />                  |      |      |

<a id="3fdd65dd82be80c4bad8cf7d07d9ce36" />Once all components for the HIFI Assembly were combined, the mixture was placed in the thermocycler.

<a id="3fdd65dd82be80b591a6cac8e9c667ea" />From NEB again thermocycle:

- <a id="3fdd65dd82be80ff8398d51e8c54c7af" />15 min at 50 deg C

<a id="3fdd65dd82be80958688e9fa039ad64f" />HIFI Assembly products were transformed via heat shock into DH5a:

1. <a id="3fdd65dd82be8065bdc5fa8632ff22ca" />Mix 9 µL of chemically competent DH5a bacteria with 1 µL of cloned plasmid (*recA* or CpxP)
   1. <a id="3fdd65dd82be80c98c56de5b9c56cc0a" />pipette up and down to mix
2. <a id="3fdd65dd82be80ca973eeb47070feb08" />Incubate on ice for 30 minutes
3. <a id="3fdd65dd82be8098b1b6e3fde84f3e48" />Heat shock at 42°C for 30 seconds
4. <a id="3fdd65dd82be8010845acd6bbc2bde34" />Incubate on ice for 5 minutes
5. <a id="3fdd65dd82be8033bf47df6008fd652c" />Add 100 µL of SOC outgrowth medium and incubate at 37°C for 1 hour
6. <a id="3fdd65dd82be8083909dd356d34ad887" />Plate 50 µL on each plate and incubate at 37°C overnight

<a id="3fdd65dd82be8081b39bcddc944bab8c" />Resulting single colonies were picked and grown in 5 mL of Cm-containing medium.

- <a id="3fdd65dd82be8085a258d8907293e603" />Incubate the colonies at 37°C while shaking overnight.

<a id="3fdd65dd82be804f8815ffe896224f0e" />Overnight liquid culture was miniprepped **based on the** [**manufacturer’s instructions**](https://www.neb.com/en-ca/protocols/monarch-plasmid-dna-miniprep-kit-protocol-t1010)

<a id="3fdd65dd82be80c68ba6fc4cc1efc9bb" />Resulting plasmids were sent for full plasmid sequencing via Plasmidsaurus

<a id="3fdd65dd82be80129728e00fa30c80ff" />Once sequencing validated the plasmids, they were transformed  into *E. coli* EPI300 strain via heatshock and plated on Cm plates

<a id="3fdd65dd82be80c8847ccc8f3da28e5d" />Resulting single colonies were saved as glycerol stocks of the patient simulant and Cm control strain
