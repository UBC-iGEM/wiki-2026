# <a id="3ead65dd82be809b811dcaeb3f3953de" />Background

## <a id="3ead65dd82be803babe8de4d5956d5a4" />Objective

<Callout icon="🗣">
  <a id="3ead65dd82be806bb24ad42f21ef32f1" />What is the response of the two biosensor strains to differing concentrations of antibiotics below its MIC?
</Callout>

<a id="3ead65dd82be80ccad6ee7acb91cb7bb" />From [Biosensor Challenge Assay](/ubc-vancouver/wet-lab/lab-notebook/biosensor-challenge-assay), we determine that the MIC of the two biosensor strains, CpxP and RecA lies between 4 µg/mL to 8 µg/mL for Tobramycin, Amoxicillin, and Gentamicin. In this experiment, we will aim to establish a dose-response curve between fluorescence and sub-inhibitory antibiotic concentrations. We will be using a set OD of 0.1 per well as the challenge assay MIC was determined with this OD.

# <a id="3ead65dd82be803d8a69e268161aa50f" />Experiment

## <a id="3ead65dd82be80858861e95b9b5bace6" />Materials and Reagents

- <a id="3ead65dd82be80adbe74cf07746c2c0f" />Gentamicin (Sigma Aldrich, #G1264-50MG)
- <a id="3ead65dd82be807fb85fd67ffb06351f" />Tobramycin
- <a id="3ead65dd82be802487f8fb4a59c8d2a2" />Amoxicillin (Sigma Aldrich, #A8523-1G)
- <a id="3ead65dd82be80f8884bfa02b05ca816" />Cephalexin (AmBeed, #A320894)
- <a id="3ead65dd82be80cd86eef24d405b9deb" />MilliQ Water

- <a id="3ead65dd82be8093b95bfb2903c0f220" />RecA and CpxP biosensor strains (from [Transformation of CpxP/RecA into EPI300](/ubc-vancouver/wet-lab/lab-notebook/transformation-of-cpxp/reca-into-epi300))

# <a id="3ead65dd82be80fda3a1d9e1ff014b35" />Procedure

## <a id="3ead65dd82be80738245fa891fe6bf5d" />Day 1 - Culture Inoculations

<a id="3ead65dd82be802dba11ce051701eed2" />Inoculate two culture tubes of approximately \~7mL of LB-Cm media with RecA and CpxP respectively. Leave overnight at 37C, shaking @ 200rpm.

## <a id="3ead65dd82be80a5a8c1ff1b57c1dc60" />Day 2 - Plating and Readout

### <a id="3ead65dd82be800e842ff6e6415fe884" />Antibiotic Reconstitution

1. <a id="3ead65dd82be8094ab5ce33a7931ba8d" />Reconstitute all three antibiotics to 100 µg/mL, correcting for potency.
   1. <a id="3ead65dd82be80d691caecaf5eb19599" />Amoxicillin: 900 µg / mg
   2. <a id="3ead65dd82be80cb874ae35bdd4499b9" />Gentamicin: 600 µg / mg
   3. <a id="3ead65dd82be8025835de58d18762067" />Tobramycin: 972 µg / mg
2. <a id="3ead65dd82be8027878ddc87068b3012" />Sterile filter all antibiotics

### <a id="3ead65dd82be8078ab28e595e14c95f0" />Working Stock Preparation

1. <a id="3ead65dd82be80379a26c10ccce7c2c5" />Into separate Eppendorf tubes, mix 80 µL of the 100 µg/mL each antibiotic stock with 920 µL of LB-Cm media to make 1 mL of working stock.

### <a id="3ead65dd82be807f9842c269cb3d422f" />Inoculum Preparation

1. <a id="3ead65dd82be802ba4e9d9a9d90ebcea" />Obtain the overnight culture and mix throughly
2. <a id="3ead65dd82be80eca444fc4667ca397f" />In a 1cm cuvette, 900 µL of LB and read $OD_{600}$
   1. <a id="3ead65dd82be80aca339f8a70b0fbc13" />Use plain LB media as a blank
3. <a id="3ead65dd82be80b0bab0ec4789c310de" />Adjust the suspension with LB to a target $OD_{600}$ of 0.2
4. <a id="3ead65dd82be8030afc1f74662b309ba" />Invert the tube to mix

### <a id="3ead65dd82be80ed9e67e1780c316334" />Plate Addition

1. <a id="3ead65dd82be80d5a996fccd78f92751" />Except for the media blank and moat wells, add 100 µL of the prepared inoculum to all interior (non-moat) wells

### <a id="3ead65dd82be8001bce3df864337c495" />Reads

1. <a id="3ead65dd82be8015957add2ff2b84aaf" />Read the OD and fluorescence of the plates immediately. After reading, return the plates to a 37C incubator.
