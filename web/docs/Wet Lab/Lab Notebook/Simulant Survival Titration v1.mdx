# <a id="3cdd65dd82be8093aeb0e22f38f060a4" />Background

## <a id="3cdd65dd82be80439ea6d4ba99b5bb5e" />Objective

<Callout icon="🗣">
  <a id="3cdd65dd82be8081b977c6a0600a9851" />**What is the maximum amount of antibiotic we can use as an input for our patient samples?**
</Callout>

<br id="3cdd65dd82be807590abcc237c07a921" />

## <a id="3d6d65dd82be8013b5aff3db597f3f86" />Variables

- <a id="3cdd65dd82be8066a38cc53646fcf976" />Independent: antibiotic concentration
- <a id="3d6d65dd82be80198e9dec6981b5962a" />Readout: $OD_{600}$ value after 24 hours of antibioitc exposure
- <a id="3d6d65dd82be809195c6ea90c5eb471c" />Objective: To find the optimal antibiotic concentration for each strain that maximises the number of colonies on the agar plate to use for future validations

## <a id="3cdd65dd82be809290fdf93eb421f915" />Procedure

## <a id="3cdd65dd82be8095b53cf8913cbc81e1" />Day 1 - Preparation of Inoculum

1. <a id="3cdd65dd82be804989bbeeb510ae8093" />Using glycerol stocks of each strain, inoculate 10 mL of the LB-Cm broth.
2. <a id="3cdd65dd82be808e84a9cf87929805c5" />Grow each strain to mid-log phase (standardize $OD_{600}$, e.g., 0.4–0.6) overnight at 37 ºC
   1. <a id="3cdd65dd82be800a93f8daf13e946b81" />LB-Gm = Gm resistant strain in LB-Cm
   2. <a id="3cdd65dd82be80c29da3ee375e26c39f" />LB-Kn = Kan resistant strain in LB-Cm
   3. <a id="3cdd65dd82be80e9b571d83202edea34" />LB-Amox = β-lactam resistant strain in LB-Cm
   4. <a id="3cdd65dd82be805681aaea7c132f0c28" />LB-Cephalexin = β-lactam resistant strain in LB-Cm

## <a id="3cdd65dd82be80379e26de12eada5d66" />Day 2 - Plating the Assay

1. <a id="3cdd65dd82be8042a3c7e0c0c149f3a1" />**Measuring** $OD_{600}$ **of starting culture:** Use a spectrophotometer or plate reader to measure the $OD_{600}$ of the culture. If $OD_{600}$ is above 0.1, dilute with fresh broth. If it's between 0.09–0.1, proceed. If below 0.09, incubate 15–30 more minutes and re-check.
2. <a id="3cdd65dd82be80908c63c58d2a5495fb" />**Prep of diluted, standardised inoculum**: Add 100 µL of $OD_{600}$-adjusted culture into 10 mL of fresh broth in a trough (a 1:100 dilution). Mix gently by pipetting up and down a few times. This gives \~10⁶ CFU/mL and is enough to inoculate about 16 rows of a 96-well plate.
3. <a id="3cdd65dd82be80e3b2e2c3a76121176f" />**Prep of antibiotic stock**: Dissolve antibiotic in broth at 2× the highest concentration to be tested. Check concentration range on literature MIC values for your strain, spanning at least several dilutions below and above that value.
4. <a id="3cdd65dd82be8090a33cfcc1da3ab40f" />Using the layout below, add 50 µL of broth to columns 1–10 of the 96-well plate. Leave column 11 empty. Add 100 µL of broth to column 12 (sterility control).

<a id="3cdd65dd82be80f6bb6adc31b5352039" />

|                                                        |                                                  |
| ------------------------------------------------------ | ------------------------------------------------ |
| <a id="3cdd65dd82be80c4ab81d90a08412883" />**Columns** | **Contents**                                     |
| <a id="3cdd65dd82be806f810be9b560bb2b96" />1           | Growth control (broth + inoculum, no antibiotic) |
| <a id="3cdd65dd82be80cba38cce504ad4f23f" />2–10        | Serial 2-fold dilution series of antibiotic      |
| <a id="3cdd65dd82be80edb24df3c8de956411" />11          | Highest antibiotic concentration                 |
| <a id="3cdd65dd82be80beaec8e9187692fc56" />12          | Sterility control (broth only, no inoculum)      |

1. <a id="3cdd65dd82be8032b971ea574fc41eaf" />**Perform the serial dilution :** Add 100 µL from 2× antibiotic stock to column 11. Using a multichannel pipette, mix and transfer 50 µL from column 11 into column 10, mix, then transfer 50 µL from column 10 into column 9, and continue this pattern down to column 2. After mixing column 2, remove and discard 50 µL so all wells end at equal volume.
2. <a id="3cdd65dd82be8085b76be11993a50d8c" />**Inoculating the plate**: Using a multichannel pipette, add 50 µL of the diluted standardized inoculum to every well in columns 1–11. Do not add inoculum to column 12 (it must stay sterile). Complete this step within 15 minutes of preparing the inoculum in Step 3.
3. <a id="3cdd65dd82be80c3be4af14521d64d95" />Seal and incubate: cover the plate with a sealing film, then a lid. Incubate at 37°C overnight.

## <a id="3cdd65dd82be80a892dfd0b274aaeeb5" />Day 3 - Read the Plate and Determine MIC

1. <a id="3cdd65dd82be80a3ac35f57e8d56f51f" />Remove the plate from the incubator, take off the lid and sealing film, and let it sit at room temperature for 15 minutes before reading.
2. <a id="3cdd65dd82be8060ada8d73315200ff7" />**Read** $OD_{600}$: Load the plate into a plate reader and record the $OD_{600}$ value for every well, including the growth control and sterility control.
3. <a id="3cdd65dd82be800ab39cf58188d059dc" />**Data analysis**: Subtract the sterility control $OD_{600}$ (background) from each well. Plot $OD_{600}$ versus antibiotic concentration (log scale on the x-axis) for each strain. Determine the MIC as the lowest concentration where no visible turbidity/growth occurs — this can be done visually or by fitting the curve with a Gompertz model for a more precise value.

# <a id="3cdd65dd82be80ffb628d74a013c917d" />Results

- <a id="3cdd65dd82be806295b9ed510bbaaddf" />Cultures were at an $OD_{600}$ of 0.6 after 26 hours of incubation at 37˚C, 250rpm.
- <a id="3ced65dd82be8070b79dd923e0811548" />To wash out the Cm from the LB-Cm, centrifuged each tube at 4000xg for 10 mins. Resuspended each pellet in 8-10ml of LB.
- <a id="3ced65dd82be80468ea1eec916799724" />Diluted to $OD_{600}$ of 0.1 by diluting 1ml of inoculum with 5ml of fresh LB
