# <a id="3c4d65dd82be8048bc80dfbc6335eae7" />Background

## <a id="3c4d65dd82be80b1ac9ae968206ae40d" />Objective

<Callout icon="🗣">
  <a id="3c4d65dd82be8087b91df370d468986d" />What is the maximum antibiotic concentration, seeding density, and the amount of time in which we get the best fluorescence from our biosensors?
</Callout>

<a id="3c4d65dd82be8081923afb4236a05290" />Previous biosensor titrations tested narrow antibiotic concentration range and did not establish the bound at which RecA and CpxP produce detectable fluorescence.

<a id="3d6d65dd82be800b9f7ccd5e042be493" />The purpose of this experiment is to identify the lower and upper bounds of detectable biosensor response to inform a more narrow range for the Biofactorial biosensor titration experiment

## <a id="3c4d65dd82be80b2bbb6da48dd1f5ca2" />Variables

- <a id="3c4d65dd82be8081b4a8c830ff09bba2" />Independent:  Seeding Density (1 concentrations, OD = 0.4), Type of antibiotic (4 of them), Antibiotic Concentration (6 concentrations), Gene (Cpxp, *recA*), Time (0–2h)
- <a id="3d6d65dd82be808baf37c02212286eb5" />Dependent: Fluorescence intensity

# <a id="3c4d65dd82be8020970ececec7905808" />Background

<a id="3d6d65dd82be808c902fd62dea2ea390" />Previously, we used bacterial cultures grown to an OD of 0.4. However, we failed to account for the dilution of the cultures once plated with antibiotic solution, diluting the final OD values to 0.2. As such, we will grow our cultures to 0.8 for a final dilution of OD 0.4.

<a id="3d6d65dd82be804c90d5f31db2a12648" />Additionally, we previously only tested 3 concentrations per antibiotic. Each showed relatively similar results except for *recA* exposed to aminoglycosides, in which concentrations did matter. If antibiotic concentration does matter, we need a much larger range of Abs to observe a difference.

<a id="3c4d65dd82be80c9a32afc3c340e4e87" />Our sensors did not display good sensitivity to antibiotic stimulation. We need to perform a more detailed biosensor output optimization experiment to determine the optimal conditions for sensor sensitivity.

## <a id="3c4d65dd82be80beaceed8dfc6d0fb9b" />Procedure

<a id="3c4d65dd82be800fa226f90844b91a77" /><u>Day 1: Prepare bacteria and antibiotic solutions</u>

- <a id="3c4d65dd82be80d1aa3edf95cc908236" />For each biosensor strain, inoculate bacteria into 50 ml of LB-Cm media (17 mg/ml). Incubate at 37˚C and 250 rpm overnight (> 16 hours).
- <a id="3c4d65dd82be80b58093ef2025c07992" />For WT, incubate at 37C and 250 rpm agitation in 50mL LB only media.

1. <a id="3c4d65dd82be80acaf07f1d5503af099" />Reconstitute antibiotics in MiliQ water and sterilize through 0.2 µM filter.
   - <a id="3c4d65dd82be805e9348d00215930a71" />Gentamicin (4 mg/ml)
   - <a id="3c4d65dd82be8077a01cf4aaf91f3e6d" />Kanamycin (20 mg/ml)
   - <a id="3c4d65dd82be8072bcc3e2ce137c6d5e" />Amoxicillin (1 mg/ml)
   - <a id="3c4d65dd82be803a8ffac5b5710865fd" />Cephalexin (2 mg/ml)
2. <a id="3c4d65dd82be80329caddd12e70b4e40" />Prepare Working Stocks from **Master Stocks** based on appropriate dilution above
3. <a id="3c4d65dd82be80a781cafaf8782c5953" />Measure the $OD_{600}$ of each overnight RecA and CpxP culture, make sure it reaches $OD_{600}$ **= 0.8**
4. <a id="3c4d65dd82be805f9843c455c25cc4ca" />Preparation of 2-fold Serial Dilutions
   1. <a id="3c4d65dd82be805a97c0c23770bab096" />Label 14 tubes for each antibiotic (1-14, Antibiotic Initial)
   2. <a id="3c4d65dd82be8046ba91d720abae0ae0" />Add 700 µl LB-Cm to tubes 2-14
   3. <a id="3c4d65dd82be8053b7a0e64a7f26a0a1" />Add 1400 µl of the highest 2X antibiotic working stock to tube 1
   4. <a id="3c4d65dd82be80dda50cdfd2c2fedb73" />Transfer 700 µl from tube 1 to tube 2
   5. <a id="3c4d65dd82be80ad8728f3e6d63caafb" />Mix tube 2 thoroughly (vortex)
   6. <a id="3c4d65dd82be8056ae12c13ca4e0d86b" />Transfer 700 µl from tube 2 to into tube 3
   7. <a id="3c4d65dd82be809c8b67e6a652ca0ee2" />Repeat sequentially through tube 13
   8. <a id="3c4d65dd82be809598e8c0a0f415018d" />Do not transfer antibiotic into tube 14, it will be the antibiotic-free LB-Cm as the 0 µg/ml control
   - <a id="3c4d65dd82be802e87a0fcbeb5f8fecd" />Each tube will contain 700 µl of antibiotic solution, 600 µl from each tube will be used for the six experimental wells (3 for each reporter), leaving 400 µl excess
   - <a id="3c4d65dd82be803c9e59f2fab5a2fd36" />Vortex each antibiotic condition thoroughly before dispersing into wells
     - <a id="3c4d65dd82be8060931cd588fcd206da" />Antibiotic solutions are prepared at 2X the desired final concentrations because they will be mixed 1:1 with bacterial culture

<a id="3c4d65dd82be80d3b9b4cbbc184c54ff" /><u>Day 2: Prepare bacteria and antibiotic solutions</u>

1. <a id="3c4d65dd82be80159facd29804eba502" />Plating:
   - <a id="3c4d65dd82be80939113c06a2341fada" />For each experimental well:
     1. <a id="3c4d65dd82be80508bd9c20a3ed4318d" />Add 100µl of the appropriate 2X antibiotic solution according to the plate layout in the Google Sheet.
     2. <a id="3c4d65dd82be800d992af9d125755e67" />Add 100µl of the appropriate culture 2X $OD_{600}$ (= 0.8 —> 0.4)
        1. <a id="3c4d65dd82be806485ecfe7939847b8e" />Final well volume 200**µl**
        2. <a id="3c4d65dd82be8086af12d16b11abf5ea" />Final concentration = 1X
   - <a id="3c4d65dd82be8059830df3a3248f78a6" />For unstimulated controls:
     - <a id="3c4d65dd82be80419706db77d6d9bda5" />100 µl bacterial culture
     - <a id="3c4d65dd82be8080979ad0ae267ece93" />100 µl antibiotic-free medium
   - <a id="3c4d65dd82be80988498e2c5a74a7069" />For blanks:
     - <a id="3c4d65dd82be80b2b6dcf50463b8e16c" />media only, no cell
   - <a id="3c4d65dd82be80eba017e36069684b03" />Water moat:
     - <a id="3c4d65dd82be80c0895ade4a6c8aec8f" />Place DI H2O in the recesses between wells.
2. <a id="3c4d65dd82be80daa53ffc8bee660ab0" />Varioskan measurement

- <a id="3c4d65dd82be80669f54d271ee14437c" />Immediately following plate preparation, begin the fluorescence assay using the Varioskan microplate reader
- <a id="3c4d65dd82be80468294fbf8475e7928" />Incubate the plate at 37C during the assay
- <a id="3c4d65dd82be80779c1ae04e8026a7b0" />Record GFP fluorescence measurement over 40mins every 10 minutes
  - <a id="3c4d65dd82be807884c6cb0c0b08c4b2" />Ex: 488 nm
  - <a id="3c4d65dd82be80a7a99cc89c8eac072e" />Em: 510 nm
  - <a id="3c4d65dd82be804ea686f4416425e631" />Record measurement over 2 hours every 10 minutes
