# <a id="3e3d65dd82be806186e4d97a357c2871" />Background

## <a id="3e3d65dd82be80b49ad6f9d47953936c" />Objective

<Callout icon="🗣">
  <a id="3e3d65dd82be801bb36ff23239466435" />What is the response of the two biosensor strains to differing concentrations of antibiotics below its MIC?
</Callout>

<a id="3e3d65dd82be80c4854ecf8e872c1a37" />From [Biosensor Challenge Assay](/ubc-vancouver/wet-lab/lab-notebook/biosensor-challenge-assay), we determine that the MIC of the two biosensor strains, CpxP and RecA lies between 4 µg/mL to 8 µg/mL for Tobramycin, Amoxicillin, and Gentamicin. In this experiment, we will aim to establish a dose-response curve between fluorescence and sub-inhibitory antibiotic concentrations. We will be using a set OD of 0.1 per well as the challenge assay MIC was determined with this OD.

# <a id="3e3d65dd82be80a081b8f5b01bddffda" />Experiment

## <a id="3e3d65dd82be80019308d36885eac28c" />Materials and Reagents

- <a id="3e3d65dd82be80bfaea0c20f2c7a04ac" />Gentamicin (Sigma Aldrich, #G1264-50MG)
- <a id="3e3d65dd82be80af9efed2fb719caa9b" />Tobramycin
- <a id="3e3d65dd82be80998d7ec0095ae1389d" />Amoxicillin (Sigma Aldrich, #A8523-1G)
- <a id="3e3d65dd82be80cd91a5c6eb979adf71" />Cephalexin (AmBeed, #A320894)
- <a id="3e3d65dd82be802b883cea14079970bb" />MilliQ Water
- <a id="3e3d65dd82be807095f7c6c0f063737e" />0.2 uM sterile filter
- <a id="3e3d65dd82be80d7b02af995d75ec824" />LB-Cm media (17 mg/L)
- <a id="3e3d65dd82be8044aa29deeeef921e1c" />RecA and CpxP biosensor strains (from [Transformation of CpxP/RecA into Epi300](/ubc-vancouver/wet-lab/lab-notebook/transformation-of-cpxp/reca-into-epi300))
- <a id="3e3d65dd82be808eb09fca4c03d8a5a1" />96-well plates, flat bottom
- <a id="3e3d65dd82be802fa80bd1c3bcc7c234" />Varioskan microplate reader

# <a id="3e3d65dd82be80338307fb718dddd915" />Procedure

## <a id="3e3d65dd82be80668f6cc036b18969b0" />Day 1 - Culture Inoculations

<a id="3e3d65dd82be80fca420f08d57e36c6c" />Inoculate two culture tubes of approximately \~7mL of LB-Cm media with RecA and CpxP respectively. Leave overnight at 37C, shaking @ 200rpm.

## <a id="3e3d65dd82be8020902fcdfaca746cbd" />Day 2 - Plating and Readout

### <a id="3e3d65dd82be805a84b0dc03f5c92456" />Antibiotic Reconstitution

1. <a id="3e3d65dd82be803aa846c932b62711bf" />Reconstitute all three antibiotics to 100ug/mL, correcting for potency.
   1. <a id="3e3d65dd82be804d94c1ebf5111a0810" />Amoxicillin: 900 µg / mg
   2. <a id="3e3d65dd82be807884b3c4f1666b8c59" />Gentamicin: 600 µg / mg
   3. <a id="3e3d65dd82be80af859dd505b7ea8c78" />Tobramycin: 972 µg / mg
2. <a id="3e3d65dd82be80dfa556dbc507813b9a" />Sterile filter all antibiotics

### <a id="3e3d65dd82be80d7a6e0f65b8ea39122" />Working Stock Preparation

1. <a id="3e3d65dd82be80a5a7c3dc2f629af972" />Into seperate Eppendorf tubes, mix 80 µL of the 100 µg/mL each antibiotic stock with 920 µL of LB-Cm media to make 1 mL of working stock.

1. <a id="3e3d65dd82be808d83d8cbfb311bcdad" />For each moat well, dispense 200uL sterile water
2. <a id="3e3d65dd82be80629e33f46f41f13604" />Dispense 100uL LB-Cm into all interior wells except column 2 (cols 3-11, rows B-G)
3. <a id="3e3d65dd82be80419f7cf9a61d194db8" />Dispense an additional 100uL LB-Cm to the sterility well (G11)
4. <a id="3e3d65dd82be80b29e24c5f07ff578c5" />Dispense 200uL of the working stock into column 2
5. <a id="3e3d65dd82be80eba793c81042937fdf" />Mix throughly (4-5 up-downs), then pipette 100uL into the next column to the right
6. <a id="3e3d65dd82be8084948cf07fe567dfc7" />Repeat step 4 until you reach column 10, discard 100uL from column 10
   1. <a id="3e3d65dd82be80b6a9e6e4416193b788" />You should have 100uL in each well, with 2x the concentration of antibiotic
7. <a id="3e3d65dd82be805e8864d8a686af3552" />Repeat steps 4-6 for all rows
8. <a id="3e3d65dd82be8040a4c3ebc6069e8d88" />When you are done with a plate, remember to place the lid back on

### <a id="3e3d65dd82be80cd8819eb45c79797b5" />Inoculum Preparation

1. <a id="3e3d65dd82be80c88be1dcd07511c35d" />Obtain the overnight culture and mix throughly
2. <a id="3e3d65dd82be8005b0c7df0ae9e4adf7" />In a 1cm cuvette, 900 uL of LB and read OD 600
   1. <a id="3e3d65dd82be80408718d1222c61ca92" />Use plain LB media as a blank
3. <a id="3e3d65dd82be80698fb2cda6d9c321c7" />Adjust the suspension with LB to a target OD600 of 0.2
4. <a id="3e3d65dd82be80c3b53bd90c3c5c36a7" />Invert the tube to mix

### <a id="3e3d65dd82be809a9608dcbfcc220792" />Plate Addition

1. <a id="3e3d65dd82be806fb2bce6bc75d07262" />Except for the media blank and moat wells, add 100uL of the prepared inoculum to all interior (non-moat) wells

### <a id="3e3d65dd82be8028a03dec2e61474df2" />Reads

1. <a id="3e3d65dd82be809f8c63d8804bb2f67e" />Read the OD and fluorescence of the plates immediately. After reading, return the plates to a 37C incubator.
2. <a id="3e3d65dd82be802ab6c9ff7680959f78" />Repeat this reading at 30min, 1hr, 2hrs, 4hrs and 8hrs

   2. <a id="3e4d65dd82be80e29932c31a26e1adae" />Next readings: 17:24, 17:54, 18:54, 20:54, 01:02

# <a id="3f3d65dd82be80d7a94de3c5dd7dfda0" />Summary

- <a id="3f3d65dd82be80fca247d22fa81c173d" />For CpxP biosensor, there are dose-dependent peaks in GFP expression between 4-8 hours of incubation:
  - <a id="3f3d65dd82be807998bee2edfc13b5e1" />**2-fold** and **3-fold increase** in GFP in **8ug/ml amoxicillin at 4–8 hrs**, relative to control
  - <a id="3f3d65dd82be80a3bbfacf5954ab256b" />GFP peaks at **4 hrs** of incubation for 8ug/ml gentamicin or tobramycin
- <a id="3f3d65dd82be80b28f12cec6cee0ee79" />RecA biosensor does not display the same dose-dependent trend, especially for aminoglycosides
  - <a id="3f3d65dd82be8071ba84db0513836923" />Only demonstrate dose-dependent GFP expression in **8 ug/ml amoxicillin** at **4–8hrs** (beta-lactam);
  - <a id="3f3d65dd82be80f2bc30f3080f07b560" />No dose-dependent response when exposed to aminoglycosides (gentamicin, tobramycin)
- <a id="3f3d65dd82be809782a2dd91c0ad7e2b" />We should repeat this experiment to confirm these trends before scaling up to biofactorial.
