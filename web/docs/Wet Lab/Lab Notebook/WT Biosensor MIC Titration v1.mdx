### <a id="3b9d65dd82be804f8eddc406879dc5e0" />Day 1  - Prep Cultures + AB stocks + Media & Water

<a id="3b9d65dd82be80169f38f773d02ffbd2" />**<u>Prepare LB Media</u>**

<a id="3b9d65dd82be800192abe9ff35c8196c" />**<u>Prepare Sterile Water</u>**

1. <a id="3b9d65dd82be8025a7cdeda968a4835b" />Fill 500mL bottle with MilliQ water, loosely cap and place autoclave tape
2. <a id="3b9d65dd82be80dcb237fd0de917495a" />Run with LB Media in autoclave on LIQUID20

<Callout icon="🥼">
  <a id="3b9d65dd82be80479c65f1e40a020fed" />\~300mL prepped and autoclaved and placed on shelf F
</Callout>

<a id="3b9d65dd82be80df871ccd5f1a1ee2e0" />**<u>WT Culture Prep</u>**

1. <a id="3b9d65dd82be8050b8bfd08e2615975f" />Add 5mL LB media to a culture tube, recap
2. <a id="3b9d65dd82be807ba72adca51e82a9eb" />Prepare an inoculation loop
3. <a id="3b9d65dd82be8049b8f7ceea2dd85c7b" />Obtain glycerol stocks from -80C (where?)
4. <a id="3b9d65dd82be8095bef4d6af759bf0ef" />Sterilize inoculation loop, when cooled, scrap top of glycerol stock with inoculation loop, place in culture tube and stir. Recap loosely
5. <a id="3b9d65dd82be80eba717c4160d70ee77" />Place glycerol tube back into -80C (where?)
6. <a id="3b9d65dd82be80cd88f1c861f1b5589e" />Place culture tube in 37C room, 200-250rpm, over night

<Callout icon="🥼">
  <a id="3b9d65dd82be8020975bc2b6e71c4b67" />10mL prepped and place on lower shaker on 37C room
</Callout>

<a id="3b9d65dd82be802c899bf2a05520c2d8" />**<u>Prepare Gentamicin and Tobramycin Stocks</u>**

1. <a id="3b9d65dd82be80eb80cbc81c49026533" />Read potency on antibiotics. Calculate amount needed to create a 1 mg/mL master stock of 15 mL
2. <a id="3b9d65dd82be80e4ae4ee5db90f3604e" />Dissolve in water, vortex, and filter
3. <a id="3b9d65dd82be8097a4b9fe7cc6693af3" />Aliquot 3mL into 5mL tubes, label with date and identity
4. <a id="3b9d65dd82be800cad22d8cc2c1e20f2" />Store in -20C

<Callout icon="🥼">
  <a id="3b9d65dd82be802e8afcf56076226d3a" />For gentamicin, the target weight for 1mg/mL in 15mL is:

  <a id="3b9d65dd82be80a386d7c392b15957b5" />$15 mL \cdot \frac{1mg}{1mL} \cdot \frac{1mg}{0.6mg} = 25mg$

  <a id="3b9d65dd82be802c9e91fde9ec661f49" />Actual weight was 27.0mg → 16.2mg active, 16.2mL MilliQ H2O added

  <a id="3b9d65dd82be80b39462c681c1a762c2" />For tobramycin, the target weight for 1mg/mL in 15mL is:

  <a id="3b9d65dd82be80a5bf9fcda36e6b87d0" />$15 mL \cdot \frac{1mg}{1mL} \cdot \frac{1mg}{0.972mg} = 15.42mg$

  <a id="3b9d65dd82be803db45ffd4672bae46f" />Actual: 16.4mg → 15.94mg active, 15.94mL MilliQ H2O added

  <a id="3b9d65dd82be80829396cfae910c0205" />All stocks aliquoted into three tubes \~5mL, one stored in 4C others in Midea -20C
</Callout>
