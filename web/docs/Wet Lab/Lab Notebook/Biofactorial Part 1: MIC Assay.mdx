## <a id="3fdd65dd82be804181f3e887ddfc33e2" />Procedure

### <a id="3fdd65dd82be807197b1e08a5218b529" />Day 1 — Culture and antibiotic stock preparation

1. <a id="3fdd65dd82be803e9942f36ef4cbe2a5" />Scrape each *E. coli* strain from library plates into separate tubes containing 10 mL LB broth.
2. <a id="3fdd65dd82be80d79ca3cd6cd04b5b2b" />Incubate overnight at 37 °C.
3. <a id="3fdd65dd82be803ebdb0c6676f4c81e0" />Prepare the four antibiotic stocks at the listed concentrations.

### <a id="3fdd65dd82be8041a4fec363d3c8034a" />Day 2 — Plate setup and inoculation

1. <a id="3fdd65dd82be80c29ae9feded608c6b0" />Load antibiotic stocks into the Echo source plate according to the antibiotic source plate layout.
2. <a id="3fdd65dd82be8043bda9f4903c4e7639" />Use the Echo to dispense antibiotics into the destination (experimental) plate according to the CSV program (see below).
3. <a id="3fdd65dd82be80f1ba18d6be33bfcf2d" />Subculture the overnight culture strains into 2mL tubes, and grow up over \~1-3 hours.
4. <a id="3fdd65dd82be800bb8e7c1ce60e24541" />Prepare one diluted *E. coli* tube per subculture with >1 mL total volume at OD 0.01:
   - <a id="3fdd65dd82be809793fefe010ceba7f4" />825 µL for 33 dispenses of 25 µL
5. <a id="3fdd65dd82be809595daeb01f5dc03d8" />For each strain, use a multichannel pipette to dispense 25 µL into each of the 32 antibiotic test wells and the AZ control well.
6. <a id="3fdd65dd82be8085a540cb1eb22fe5ca" />Prepare the P24 media control well with 25 µL LB.
