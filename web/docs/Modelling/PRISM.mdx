# <a id="3fcd65dd82be80e9bed1f5180f50e1b2" />Introduction

<a id="3fcd65dd82be80f8a53efbbd4bc7f826" />FAST requires promoters that respond to antibiotic exposure and can activate a measurable reporter. Antibiotic treatment can change the expression of thousands of genes, so identifying an antibiotic-responsive promoter involves integrating many factors. PRISM corroborates *Escherichia Coli* expression data with regulatory interactions, promoter annotations, and sequencing information.

<a id="3fdd65dd82be80bb9ef0facec0c9b7e7" />Our contribution is the integration, interpretation and review workflow. The expression model, source measurements, and regulatory annotations come from the cited methods and resources. PRISM makes their relationships inspectable and produces a reproducible selection proposal.

<a id="3fdd65dd82be80dabb7ed635d244a680" />PRISM produces differential-expression evidence, regulatory context, promoter and transcription unit mappings, candidate assessments, a proposed first-pass screening panel, and a searchable database.

# <a id="3fcd65dd82be80d0a284d41cc22f0417" />Database

<a id="3ffd65dd82be8075bd2ffe80102a77e6" />PRISM stores datasets, genes, antibiotics, contrasts, differential-expression results, regulatory interactions, promoters, transcription units, candidate evidence, proposed panels, assessments, replicate summaries, and fragment reviews in a relational SQLite database.

<a id="3ffd65dd82be805b98e8fc810c3e2771" />A candidate record represents gene-level evidence. A separate many-to-many relationship links candidate genes to possible promoters. The panel records the specific promoter proposed for testing. Source loci remain associated with individual expression results. Identifier mappings retain the source row, reference release, and mapping basis. This allows the database to represent cases in which one symbol maps to multiple source loci.

<a id="3ffd65dd82be800583c8d535949d00b6" />

| <a id="3ffd65dd82be80c99c67ee552aed7e02" />Record                         | Key relationship                                                | Representation                                            |
| ------------------------------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------- |
| <a id="3ffd65dd82be802aaac1e00835d0e419" />Analysis run                   | One run has contrasts, results, candidates, and imported assets | A versioned build with recorded input and code provenance |
| <a id="3ffd65dd82be801ea961f2b4c6ce839f" />Differential-expression result | One row per run, contrast, and source gene                      | A gene-level estimate and uncertainty from RNA-seq        |

## <a id="3ffd65dd82be807d8c97da58b85a85d0" />Integrity checks and  limits

<a id="3ffd65dd82be807dbc81da5be0e76be6" />The builder verifies the benchmark configuration, source archives, differential-expression exports, and pairwise comparison file against the recorded benchmark provenance. Before import, it also checks that duplicated candidate evidence agrees with the matching source-locus DE result. Panel entries must use a promoter already mapped to that candidate, and the schema enforces the same relationship with a composite foreign key. Regression tests cover stale exports, inconsistent evidence, and unrelated panel promoters. These checks make the current build safer to reproduce. They do not check the statistical model or that the biological annotations are correct.

# <a id="3ffd65dd82be80a3aa7adf1d12355de7" />FAST project context

<a id="3ffd65dd82be803383edc4c8de7f625b" />The Fluorescent Antibiotic Susceptibility Test (FAST) aims to identify promoters that respond to antibiotic exposure and can drive a measurable reporter. Antibiotic treatment can alter many genes. A change in gene expression alone does not identify the responsible promoter, establish antibiotic specificity, or show that the promoter will function in a reporter construct.

<a id="3ffd65dd82be809f867efc2a77c24040" />PRISM links differential-expression results to curated regulatory factors, transcription units, promoter annotations, and reference-genome sequences.

<a id="3ffd65dd82be80c49f25ca5846daeaae" />PRISM integrates and presents expression evidence with curated regulatory annotations in a reproducible review workflow. The expression model, source measurements, and annotations come from published methods and reference resources. The proposed panel requires experimental testing in FAST’s reporter system.

<a id="3ffd65dd82be806ea655cec7fb02023f" />PRISM produces differential-expression evidence, regulatory context, promoter and transcription-unit mappings, candidate assessments, a proposed initial screening panel, and a searchable evidence database. The analysis included 4,176 measured genes, identified 925 candidate genes, and produced a proposed panel of 12 promoters.

# <a id="3ffd65dd82be80028b45d71f35249a5d" />Pipeline

<a id="3fdd65dd82be8038a5dce6a7e21ef457" />PRISM combines RNA-seq data with regulatory and genomic annotations. The pipeline connects pieces of evidence and filters to produce promoter candidates for experimental screening. Each output retains a link to the source data which allows for review and reproducibility.

<a id="3fdd65dd82be8099bdd8dacbac38fb7c" />PRISM combines expression measurements, regulatory annotations a strain specific reference genome, and an analysis configuration. These inputs were chosen to keep the analysis consistent internally as PRISM favours traceability within one dataset and strain. Dataset GSE220559 provides antibiotic test conditions to reference. Due to the lack of available data directly applicable to our project, ceftazidime and kanamycin serve as `β-lactam` and aminoglycoside proxies respectively.  Ciprofloxacin and polymyxin E act as cross-reactivity challenges while imipenem checks for study robustness.

## <a id="3fdd65dd82be8059a61dfb30dc23998a" />Input Validation

<a id="3fdd65dd82be809bb08ff9ee02edfbb4" />Data validation is one of the important preprocessing steps of the data pipeline. Checks are implemented at multiple steps. Valid inputs are checked through whether sample identifiers and count matrix columns agree. Shared water controls are compressed to one set use for the final model.

## <a id="3fdd65dd82be80cb9973c6dc16464de5" />Design Choices

### <a id="3fdd65dd82be8037b065eec1d2cf06f4" />One expression model

<a id="3fdd65dd82be809a920bd2b3f81095b8" />All conditions were fitted in one model so that they shared the same normalisation, gene filter, and statistical framework. The count model follows DESeq2, implemented using PyDESeq2. The model uses raw integer counts and estimates dispersion using information across genes.

### <a id="3fdd65dd82be80cf80fffc992f812242" />Antibiotic roles labelled

<a id="3fdd65dd82be808e9880ed27aeedd184" />Each antibiotic was assigned a defined role: discovery proxy, robustness comparison, or cross-reactivity challenge. This prevents PRISM from treating every drug as equivalent to a wetlab target.

### <a id="3fdd65dd82be80498011ea3c11ed529c" />Candidate selection

<a id="3fdd65dd82be80ee973fcdba95bf6afb" />Candidate genes were required to have an adjusted p-value below 0.05 and a log2 fold change greater than 2. These are screening thresholds chosen to prioritise strong, statistically supported induction; they are not universal biological boundaries.

<a id="3fdd65dd82be80988308c0538df20257" />Benjamini–Hochberg adjustment is applied separately to each antibiotic-versus-control contrast. The combined set of genes selected across contrasts has not been shown to have a 5% false-discovery rate. The ten pairwise antibiotic comparisons are adjusted before use in candidate selection. Shrunk effect estimates are used for ranking. Unshrunken estimates are used to seed candidates <Cite refs={[{"n":4,"key":"benjaminiControllingFalseDiscovery1995"},{"n":5,"key":"zhuHeavytailedPriorDistributions2019"}]} />.

### <a id="3fdd65dd82be80489d4cf7517e049cc1" />**Full measured background**

<a id="3fdd65dd82be805eb3e1dd82179160ad" />Regulon enrichment used all eligible measured and mapped genes as the background. Using only selected candidates as the background could inflate enrichment estimates.

### <a id="3fdd65dd82be808695bfce847b20a8ba" />Regulatory evidence

<a id="3fdd65dd82be802595ebd647646fd923" />PRISM keeps direct curated regulation separate from promoter, transcription-unit, and gene membership. Missing links remain visible rather than being filled with unsupported assumptions.

### <a id="3fdd65dd82be80ff81a7ed6647394128" />**Balanced screening panel**

<a id="3fdd65dd82be80459f1ed868cf9e468c" />The proposed panel contains six candidates per antibiotic class and limits repeated promoters or connected transcription-unit groups. It uses a deterministic greedy rule: supporting comparisons, threshold-screen stability, promoter annotation confidence, regulator reuse, direct comparisons, counterpart effects, and shrunken induction, with identifiers breaking remaining ties. This is a screening heuristic; information gain and biological optimality have not been established.

### <a id="3fdd65dd82be8082bdbad7cdbe4ba2a5" />**Relational evidence database**

<a id="3fdd65dd82be80858deed6c18bf6bf8a" />SQLite was chosen because PRISM contains many linked record types: genes, treatments, comparisons, promoters, regulators, candidates, assessments, and source assets. Stable relationships allow every candidate decision to be traced back to its raw data and evidence.

### <a id="3fdd65dd82be80dd9aabf4d02c3052d3" />**Review history**

<a id="3fdd65dd82be806f93b0f6c3de10ea17" />Manual decisions are stored separately from imported measurements. Reviewers can approve, exclude, or annotate candidates without altering the underlying scientific evidence.

## <a id="3fdd65dd82be8077bb0ff8c955ac0091" />**Expression Data to Promoter Candidates**

1. <a id="3fdd65dd82be80019595f65839172287" />**Verify source data:** PRISM checks required datasets, reference versions, and source-file hashes before analysis.
2. <a id="3fdd65dd82be8020bdd2d344149da9ea" />**Fit the expression model:** A joint differential-expression model compares each antibiotic condition against the shared water control.
3. <a id="3fdd65dd82be80e5abacdec5ed25b720" />**Identify responsive genes:** Genes passing the expression, effect-size, and adjusted p-value thresholds become candidate seeds.
4. <a id="3fdd65dd82be80788547f1d1904c2ca5" />**Add curated regulatory context:** Candidate responses are overlaid onto curated relationships among regulators, promoters, transcription units, and genes.
5. <a id="3fdd65dd82be807eb25eebd729c97d09" />**Map candidate promoters:** PRISM identifies promoter records associated with each candidate gene and checks available coordinates against the MG1655 genome.
6. <a id="3fdd65dd82be802d83defb2ba0b212e6" />**Assess candidate quality:** Candidates are evaluated for replicate consistency, threshold stability, cross-reactivity, operon support, and sequence availability.
7. <a id="3fdd65dd82be8080a5fcdff53ff923c8" />**Select the screening panel:** A balanced first-pass panel is created while limiting repeated promoters and connected transcription-unit groups.
8. <a id="3fdd65dd82be802bb601ef97999d42b0" />**Build the evidence database:** Expression results, regulatory paths, promoter records, assessments, and provenance are imported into a searchable SQLite database.

## <a id="3fdd65dd82be802a9b32d7a4db5f4c8b" />Pipeline Outputs

<a id="3fdd65dd82be804b99c2c1237d79ed41" />PRISM records reference releases, configuration values, source hashes, and analysis provenance. A failed stage stops the workflow, and the database is replaced only after the new build passes validation.

# <a id="3ffd65dd82be8052b4d9f8eb394a2419" />Expression analysis

<a id="3ffd65dd82be80be8cc5f6f3916410a1" />The primary benchmark contains 18 unique RNA-sequencing (RNA-seq) samples: three biological replicates for each condition, including shared water controls. Five antibiotic-versus-water comparisons and ten pairwise comparisons between antibiotics were fitted in one PyDESeq2 model using condition as the design variable.

# <a id="3ffd65dd82be80369e0ae41b4737cb1a" />Curated regulatory context

<a id="3ffd65dd82be809f892aef4ac5a40d44" />Gene-level differential expression does not by itself identify a constructable promoter. PRISM therefore overlays candidate responses onto curated RegulonDB relationships among regulators, promoters, transcription units, genes, and regulatory sites.

<a id="3ffd65dd82be8004ba53ee3b2c942084" />

<Figure imgs={[{"url":"https://static.igem.wiki/teams/6279/wiki/assets/f212b1d1bd9c5b81afade54c830a931c.svg","alt":"","scale":0}]}>
  <Fragment slot="content">
    <a id="3ffd65dd82be80e481e1c89142a2ad79" />**Example regulatory context:** The `pdhRp2` promoter is associated with the `pdhR` transcriptional unit and curated regulatory effects from PdhR, CRP, and FNR. The diagram summarises reference annotations. Labels identify activation, repression, and mixed effects. These annotations do not show that the regulators cause the observed antibiotic response.
  </Fragment>

<a id="3ffd65dd82be80eeb989de203ce9876d" />PRISM distinguishes curated regulatory interactions from promoter, transcription-unit, and gene membership. Solid edges show curated regulation of the recorded target. Dashed edges show annotated membership. A gene-target interaction is not treated as direct regulation of a promoter.

<a id="3ffd65dd82be8043ab21e231e9a21d0c" />The integrated reference contains 6,460 curated interactions, 4,057 promoters, and 3,767 transcription units. Of the 6,460 interactions, 729 do not have an associated promoter record and remain available for review.

<a id="3ffd65dd82be80c5ab8dd79dc432659d" />An earlier database build reported 3,780 transcription units because 13 comma-separated lists had been imported as single identifiers. The schema version 12 import now separates these lists and checks memberships against the reference. A regression test covers this case. The correction changed the database representation, but not the expression fit or selected panel.

<a id="3ffd65dd82be80f4b612c65c6a818e15" />Regulon enrichment uses all eligible measured and mapped genes as its background. Fisher’s exact tests with Benjamini-Hochberg correction provide exploratory gene-level evidence. Correlation among genes in operons limits the independence of these observations.

<a id="3ffd65dd82be80b7b11afdd8bb33ba17" />This background defines which genes could enter the analysis. It does not remove all detection bias or account for correlation between genes. These remain limitations of the exploratory enrichment results.

### <a id="3ffd65dd82be80c696caed152c914bd0" />Database integrity and identifier mapping

<a id="3ffd65dd82be800ca597f0a00e13733b" />Adversarial review found that a stand alone build could accept a modified DE export while retaining stale candidate evidence. It also found that a panel row could pair a candidate with an unrelated promoter that existed elsewhere in the database. The builder now checks the DE artifacts against benchmark provenance, compares duplicated candidate evidence with the imported DE result, and rejects unmapped panel promoters. Regression tests exercise these failures and confirm that a failed build leaves the prior database intact.

<a id="3ffd65dd82be80899f24c71a9bac371c" />The database also retains source-linked identifier associations and uses composite foreign keys for run, contrast, and candidate–promoter relationships. Regression tests check locus searches, distinct source loci, ambiguous identifiers, inconsistent run links, sample context, unknown values, and retention of superseded evidence snapshots. These tests demonstrate software behaviour. They do not validate promoter activity or independently reproduce the upstream statistical model.

## <a id="3ffd65dd82be80e9a824fdb1da0f1aed" />Biological validation still required

- <a id="3ffd65dd82be8090974ce98c90c3ed1b" />Clone selected promoter fragments upstream of a reporter
- <a id="3ffd65dd82be802fb617d9d3e7b2ce85" />Test the exact target antibiotics at multiple doses and time points
- <a id="3ffd65dd82be801ab6ace81c0dedc50e" />Include untreated, general-stress, and off-target controls
- <a id="3ffd65dd82be8012b480f8ae7f1028db" />Compare susceptible and resistant backgrounds where feasible
- <a id="3ffd65dd82be8089849edac1a98d52f1" />Normalise fluorescence to growth
- <a id="3ffd65dd82be8076b581df060ce64031" />Evaluate response magnitude, response time, specificity, and reproducibility

<a id="3ffd65dd82be807ba688d15ad02e9f47" />Before collecting reporter data, define the experimental unit and distinguish biological from technical replicates. Record the construct sequence and version, chassis, reporter and vector context, batch, plate and well, compound, dose and units, and exposure time. Preserve raw fluorescence and growth measurements together with normalisation and quality-control decisions. Define inclusion and exclusion rules and acceptance thresholds before evaluating the panel.

### <a id="3ffd65dd82be80589fa4ce7349f81aaf" />Reporter assay design

<a id="3ffd65dd82be80b6b5a2c44e8c3ba85b" />The next experiment should distinguish promoter response from changes in the measurement system. Include a promoterless control and a reference construct. Record the complete construct sequences and measurement conditions. These controls follow established in vivo promoter-characterization practice <Cite refs={[{"n":6,"key":"kellyMeasuringActivityBioBrick2009"}]} />.

<a id="3ffd65dd82be80748e40e841fa7bbda6" />Reporter maturation delays the appearance of fluorescence after transcription. An RNA response may therefore differ from the measured fluorescence response. Reporter performance must be measured under the target conditions <Cite refs={[{"n":7,"key":"ballezaSystematicCharacterizationMaturation2018"}]} />.

<a id="3ffd65dd82be8080b221cd5b2bbfeccf" />Preserve raw fluorescence and optical-density measurements, instrument settings, and calibration records. PRISM has not yet collected these measurements.

# <a id="3fcd65dd82be8072bdf4cbde9bb1863a" />Discussion

## <a id="3ffd65dd82be80dfab37c2972453de30" />Project outputs

<a id="3ffd65dd82be80bb9842ee16668af0fb" />PRISM’s main contribution is a database and review workflow that links gene-expression results with source identifiers, curated regulatory relationships, promoter annotations, candidate assessments, and analysis provenance. The explorer and programmatic interfaces let users inspect these linked records, while the curation archive preserves review decisions separately from measured data.

<a id="3ffd65dd82be800b96f7d5ed71fd8bbe" />The FAST case study shows how this structure can support a screening decision. The analysis identified 925 candidate genes, but only 469 had promoter mappings and were eligible for the current panel. PRISM used expression evidence, annotation support, and diversity criteria to propose 12 promoters. This narrows the set for experimental review and makes the basis for each selection traceable.

## <a id="3ffd65dd82be8083bbfccd6dbb56ade0" />Limitations

<a id="3ffd65dd82be80ec9149f181b71e0e7e" />The current importer and analysis are based on one transcriptomic study of *E. coli* K-12 MG1655, with three biological replicates per condition and shared water controls. The discovery compounds are class proxies, not the four antibiotics planned for FAST. Gene-expression changes do not identify promoter activity, and the current analysis has no held-out biological validation or reporter measurements.

<a id="3ffd65dd82be80e782d6f94001c33fea" />The database also depends on the completeness of its source annotations. Of the 925 candidate genes, 456 have no promoter mapping, and some promoter records lack coordinates. This creates annotation-dependent selection bias: an unmapped gene is not necessarily a weak candidate. Correlation among genes in operons also limits how enrichment results can be interpreted. The numeric antibiotic concentrations and elapsed times before RNA sampling have not been curated, so the transfer of those results to FAST conditions remains uncertain.

## <a id="3ffd65dd82be800caeb9ea69aa135f95" />Future improvements

<a id="3ffd65dd82be80e68cbbd8c996a217cc" />The next stage is to test the 12 proposed promoter fragments in the FAST reporter system using amoxicillin, cephalexin, gentamicin, and tobramycin. Experiments should include a range of doses and time points, untreated and off-target controls, and growth measurements alongside fluorescence. The exact construct sequences and assay conditions should be recorded so results can be compared and reviewed.

<a id="3ffd65dd82be805abc2fddf0f86856e4" />PRISM should then link each construct and measurement to its candidate record, including construct version, chassis, compound and dose, exposure time, plate and well, replicate type, raw fluorescence and growth values, and quality-control decisions. Experimental results can be used to reassess candidate ranking and identify where the database needs additional fields or curation rules. Support for other studies would require a separate importer adapter and validation.
