## <a id="3e5d65dd82be8079af05c75febc5617c" />Method

<a id="3e8d65dd82be80878d35e3da3a754df1" />The objective of the Promoter Library was to identify top promoter candidates out of a library of over 200 promoter candidates. The library consisted of promoter-GFP constructs on well plates. The antibiotic response of these constructs were unknown, as well as the promoter barcodes. Our experiment consisted of three parts: an assay development to select sub-inhibitory concentrations for each antibiotic, the high-throughput library screen exposing the promoter-GFP plates to the antibiotics at the selected concentrations, and then finally Sanger sequencing the top candidates. As we had over 200 promoter candidates, doing this experiment on our own bench top would not be effective. Thus, we collaborated with Biofactorial, a High-Throughput Biology and Automation Facility here at UBC’s Life Sciences Institute. Biofactorial was able to execute the assay testing and library screen for us, so we worked in collaboration to develop the proposal and experimental design.

<a id="3fcd65dd82be80bdb51cf62054830b9f" />Note: complete protocols can be found under Wet Lab - Lab Notebook

<a id="3f9d65dd82be8014888ace9e8aff5203" />**Part 1: Identifying Sub-inhibitory Concentrations**

<a id="3f9d65dd82be80958a9eeb4fa987baf4" />Before beginning the library screen, it was critical to first develop an assay to select sub-inhibitory concentrations for each antibiotic that we would expose the library to during the subsequent screening. We used literature minimum inhibitory concentration (MIC) values as a reference point for our experimental design, creating a dilution series around the literature MIC values to capture a curve.  Literature review was also conducted on all of the antibiotics to ensure solubility at low concentrations.

<a id="3e5d65dd82be807eabedf015927c482f" />**Part 2: High-throughput Library Screen**

<a id="3e5d65dd82be8082b49fd23996e892d8" />The objective of part 2 was to now conduct the entire library screen by exposing all promoter-GFP constructs to the antibiotics at the appropriate concentration levels determined from part 1. This required creating 5 replicates of the library plates, so we could expose the library to each of the four antibiotics while having one control plate with no antibiotic exposure. In total, we had 30 plates. Biofactorial was able to carry out the plate replication for us, however, this time instead of using the Echo Acoustic Liquid Handler to dispense from the antibiotic source plates, an alternative pinning machine was used dispensing 70μl rather than the original 50μl. This simply meant that our starting OD600 was slightly higher, but this did not impact our results. From here, the E. coli plates were incubated with LB media and the antibiotic for 8 hours, following the same data collection guidelines as part 1: measure OD600 every 30 minutes along with GFP fluorescence with 488 nm excitation and detected at 510 nm emission.
