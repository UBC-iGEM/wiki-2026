# <a id="3fcd65dd82be80afb02ecf242a9db481" />What is antibiotic susceptibility?

<a id="3fcd65dd82be8085834cd3ef8c7a5979" />Antibiotic susceptibility determines whether a biological organism, mainly cells, can be killed by antibiotics. Through evolution, various species of pathogenic bacteria have acquired antibiotic immunity, rendering them unsusceptible to certain antibiotics.
